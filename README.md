# EduNote

교직원과 공무원을 위한 AI 데스크톱 앱입니다. 학생기록, 교무행정, 수업자료 제작에
반복적으로 들어가는 문서 작업을 줄이는 것을 목표로 합니다.

- 소개 페이지: https://edunote-kappa.vercel.app
- 다운로드: [최신 릴리즈](https://github.com/codersongpro/edunote/releases/latest)

---

## 주요 기능

| 영역 | 내용 |
|---|---|
| **학생기록AI** | 행동특성 및 종합의견, 교과 세부능력 및 특기사항, 창의적 체험활동, 학교스포츠클럽 특기사항 작성 보조. 학생 메모와 학생 카드로 개별 기록 관리 |
| **교무행정AI** | 공문서(겉공문), 계획서, 결과보고서, 가정통신문, 공고문, 회의록, 지출품의서, 알림 문자 작성. 공문 분석 요약, 예산안 작성 |
| **수업자료AI** | 수업 슬라이드, 워크시트·평가지, 수업계획서, 퀴즈, 수업 게임 생성 |
| **내 스킬** | 사용자가 직접 프롬프트와 입력 항목을 정의해 만드는 개인 도구 |

부가 기능으로 한글(HWPX) 문서 내려받기, 인쇄용 서식, 번역, 뽑기, QR 만들기,
학급 채팅방 등이 포함되어 있습니다. 자세한 변경 내역은
[RELEASE_NOTES.md](RELEASE_NOTES.md)를 참고하세요.

## 사용 환경

- Windows 10 / 11 (64비트)
- 설치가 필요 없는 포터블 실행 파일
- Google AI Studio에서 발급한 무료 API 키 필요 — https://aistudio.google.com/apikey

---

## 데이터 보관 방식

- 학생 정보와 생성 결과는 **사용자 컴퓨터에만 저장**되며 별도 서버로 전송되지 않습니다.
- API 키는 운영체제의 안전 저장소로 암호화해 보관합니다.
- 개인정보 보호 모드를 켜면 학생 이름을 임시 토큰으로 바꿔 전송하고, 결과를 받은
  뒤 원래 이름으로 되돌립니다.
- 생성 결과는 초안입니다. 반드시 검토·수정한 뒤 사용하시기 바랍니다.
