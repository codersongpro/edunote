# EduNote 개발 일지

작성 기준: 2026년 6월 2일
작성 목적: 개발 보고서 작성용 요약 자료
대상 범위: 초기 구현부터 v1.10.5 릴리즈까지

## 1. 개발 개요

EduNote는 교사의 학생기록 작성, 교무행정 문서 작성, 수업자료 제작, 업무 추출을 하나의 데스크톱 앱에서 처리하기 위해 개발한 교육 업무 보조 도구이다. 초기 버전은 학생기록 AI와 교무 AI 기능을 중심으로 출발했으며, 이후 실제 학교 업무 흐름에 맞추어 수업자료 생성, 자료실, 학생 메모, 공문 요약, 캘린더 연동, 나만의 AI 스킬 만들기, HTML 앱 제작, 릴리즈 자동화 기능을 단계적으로 확장하였다.

개발 과정은 사용자가 실제로 앱을 실행하며 발견한 불편을 빠르게 반영하는 방식으로 진행되었다. 특히 Windows 환경에서 바로 실행할 수 있는 portable EXE 배포, API 키 사용성, 다크모드, 생성 중단, 동시 생성, 학교 현장 문서 양식 개선에 중점을 두었다.

### 1.1 업데이트 의도

EduNote의 업데이트는 단순 기능 추가보다 교사의 실제 업무 흐름을 줄이고, 생성 결과물을 학교 현장에서 바로 검토·수정할 수 있는 수준으로 다듬는 데 목적을 두었다. 초기에는 학생기록과 교무행정 문서 작성 보조에 집중했으나, 이후 수업자료 제작, 업무추출, 자료관리, 백업, 교육용 게임 실행 등 교사가 하루 업무 안에서 반복적으로 수행하는 작업을 하나의 앱 안에 모으는 방향으로 확장하였다.

주요 업데이트 의도는 다음과 같다.

- 학생기록, 상담, 수업관찰, 창체, 교과세특 작성 과정에서 교사가 문장 초안을 빠르게 확보할 수 있도록 지원
- 공문서, 계획서, 보고서, 품의서, 회의록, 공고문 등 학교 업무 문서의 형식과 문체를 실제 행정 문서에 가깝게 정리
- 수업자료 생성 결과를 슬라이드, 워크시트, 퀴즈, 수업 계획서, 교육용 게임 등 바로 활용 가능한 형태로 제공
- 학생 명단과 개인정보가 불필요한 기능에 자동 반영되지 않도록 제한하여 개인정보 최소화 원칙 반영
- 생성 결과물에서 AI가 작성한 느낌, 반복 문구, 불필요한 기호, 어색한 문체를 줄여 공적 문서 품질 개선
- Windows 교사 PC에서 설치 부담 없이 실행할 수 있도록 portable EXE 방식의 배포 유지

## 2. 사용 프로그래밍 언어 및 기술 스택

EduNote는 Windows 환경에서 교사가 별도 서버 구축 없이 실행할 수 있는 데스크톱 애플리케이션을 목표로 개발하였다. 이를 위해 웹 기반 UI의 빠른 개발성과 데스크톱 앱의 파일 저장·로컬 데이터 접근 기능을 함께 활용할 수 있는 Electron 기반 구조를 채택하였다.

### 2.3 프론트엔드 및 사용자 인터페이스

프론트엔드는 React 19와 TypeScript를 기반으로 구성하였다. 학생기록AI, 교무행정AI, 수업자료AI를 각각 독립 화면으로 나누고, 사용자가 메뉴를 이동해도 생성 작업이 유지되도록 상태 관리 구조를 설계하였다. 아이콘은 lucide-react를 사용해 메뉴, 버튼, 상태 표시를 직관적으로 표현하였다.

화면 스타일은 Tailwind CSS와 PostCSS를 사용하였다. 다크모드, 반응형 레이아웃, 입력 폼, 탭, 버튼, 알림 배지 등 반복되는 UI 요소를 일관된 스타일로 유지하는 데 활용하였다. 사이드바 메뉴는 섹션별로 드래그하여 순서를 변경할 수 있으며, 변경된 순서는 localStorage에 저장된다.

### 2.4 데스크톱 앱 구조

앱은 Electron 30 기반으로 구성하였다. Electron의 main process는 파일 저장, 폴더 선택, PDF 생성, 웹페이지 메타데이터 수집, 로컬 데이터 백업 같은 운영체제 연동 기능을 담당한다. renderer process는 React 화면과 사용자 상호작용을 담당하며, preload script를 통해 안전하게 Electron IPC 기능에 접근하도록 구성하였다.

### 2.5 AI 및 생성 서비스

AI 생성 기능은 Google Gemini API와 `@google/genai` 라이브러리를 기반으로 구현하였다. 무료 등급에는 `gemini-2.5-flash-lite`, 유료 등급에는 `gemini-2.5-pro` 모델을 사용한다. 학생기록, 교무행정 문서, 수업자료, 공문 요약, 이미지 생성 요청을 각각 다른 프롬프트와 시스템 지침으로 분리하였다.

### 2.6 로컬 데이터와 백업

사용자 설정은 electron-store를 활용해 로컬에 저장하였다. 학생 명단, 나만의 자료실, 학생 메모 등 계속 불러와야 하는 자료는 JSON 파일로 관리하였다. 전체 자료 백업 기능으로 기본 정보, 학생 명단, 자료실, 메모 데이터를 하나의 JSON 파일로 내보내고 다른 컴퓨터에서 불러올 수 있다. Gemini API 키는 백업 파일에 포함하지 않도록 설계하였다.

### 2.7 문서 생성 및 파일 처리

PDF 저장은 Electron의 `printToPDF` 기능을 활용하였다. HWPX 관련 실험에는 JSZip과 `@xmldom/xmldom`을 사용해 문서 내부 XML 구조를 분석하고 템플릿 치환 가능성을 검토하였다. HWPX 기능은 문서 구조 보존 안정성이 충분히 확보되기 전까지 `(구현중)`으로 표시하도록 정리하였다.

### 2.8 빌드와 배포

개발 빌드는 electron-vite와 Vite를 사용하였다. Windows 배포 파일은 electron-builder를 통해 portable EXE 형태로 패키징하였다. Git과 GitHub를 사용해 버전별 변경 이력을 관리했으며, 릴리즈 파일은 로컬에서 실제 EXE 빌드 검증 후 GitHub Releases에 직접 업로드하는 방식으로 운영하였다.

## 4. 주요 개발 성과

### 4.1 교사 업무 흐름 중심의 기능 통합

EduNote는 학생기록 작성, 상담일지, 수업관찰기록, 공문서 작성, 수업자료 생성, 업무추출을 하나의 앱 안에서 연결했다. 교사가 여러 웹서비스와 문서 도구를 오가며 처리하던 업무를 한 화면에서 시작하고 결과를 저장할 수 있도록 구성했다.

### 4.2 학교 현장 문서 양식 반영

공문서 작성기에는 공문, 계획서, 보고서, 품의서, 회의록, 홍보자료, 가정통신문, 문자 및 소통메시지, 공고문 등 학교에서 자주 쓰는 문서 유형을 반영했다. 공문서·품의서는 합쇼체, 계획서·보고서는 보고서체 문체를 분리하여 각 문서 유형에 맞는 언어 품질을 확보했다.

### 4.3 수업자료 제작 기능 확장

수업 슬라이드, 워크시트, 퀴즈, 수업 계획서를 생성하도록 확장했다. 생성 결과는 편집 가능하도록 개선했고, 수업 계획서는 표 중심으로 출력되도록 하여 인쇄와 검토에 적합하게 정리했다. 퀴즈는 객관식·주관식·OX 유형을 체크박스로 선택할 수 있으며, JSON 데이터와 고정 템플릿 방식으로 생성하여 모든 유형이 항상 안정적으로 동작한다.

### 4.4 개인정보와 사용자 통제 강화

학생 명단은 필요한 기능에서만 사용하도록 조정했다. 수업자료 생성의 추가 요청사항에는 학생 명단이 자동 입력되지 않으며, 사용자가 직접 불러왔을 때만 반영되도록 했다. 공문서 작성기에서는 학년도, 날짜, 소속기관만 문맥상 필요한 경우 참고하도록 제한했다.

### 4.5 나만의 AI 스킬 기능 추가

v1.10.0부터 교사가 코드 없이 직접 AI 작업 패턴을 만들 수 있는 '내 스킬' 기능을 추가했다. 3단계 위저드로 입력 필드와 프롬프트 템플릿을 구성하거나, AI와 대화하면 자동으로 스킬 초안이 생성된다. v1.10.1에서는 HTML 앱 제작 기능을 추가하여 팀 점수판·수업 타이머 같은 인터랙티브 앱을 설명만으로 만들 수 있게 되었다. 스킬은 JSON 파일로 내보내고 가져올 수 있으며, 공유 마켓을 통해 동료 교사와 나눌 수 있다.

### 4.6 배포와 유지보수 체계 정비

Windows 사용자가 별도 설치 없이 실행할 수 있도록 portable EXE 배포 방식을 유지했다. v1.10.0부터 main 브랜치에 `package.json`이 변경된 상태로 push되면 GitHub Actions가 Windows EXE를 자동 빌드하고 릴리즈를 생성 또는 갱신한다.

## 5. 최근 릴리즈 요약

v1.9.0은 사이드바 구조를 정리한 릴리즈이다. 교사 기록·수업 도구 메뉴를 탭 형태로 통합하고, 설정·Demo 버튼을 사이드바 하단에 배치하였다. 메세지 메뉴를 탭 구조로 개선하여 SMS와 소통메세지를 한 화면에서 선택할 수 있게 하였다.

v1.9.1은 사이드바 트리 메뉴를 개선한 릴리즈이다. 생기부도우미·우리반기록·수업 도구를 펼침/접힘 트리로 분리하여 메뉴 탐색을 명확하게 하였다.

v1.9.2는 수업자료 기능을 높인 릴리즈이다. 워크시트 제목 정렬 강화, AI 이미지 삽입 기능 추가, Demo 창을 별도 창으로 분리하였다. 모든 생성물의 날짜·학년도 기준을 현재 날짜로 자동 통일하였다.

v1.10.0은 내 스킬(AI스킬즈) 기능을 신규 추가한 릴리즈이다. 3단계 위저드 또는 AI 대화형으로 프롬프트 스킬을 만들고, 파일 첨부·배치 처리·타임아웃·취소 기능을 갖춘 실행 화면을 제공한다. 마켓플레이스와 JSON 파일 공유로 동료 교사와 스킬을 나눌 수 있다.

v1.10.1은 스킬 기능을 확장하고 안정성을 높인 릴리즈이다. AI에게 설명하면 HTML 앱(팀 점수판·수업 타이머 등)을 즉시 만들어 주는 기능을 추가하였다. 수업 타이머 샘플 앱이 내장되어 있어 바로 사용할 수 있다. 사이드바와 탭 이름을 '내 스킬'로 통일하고, 스킬 카드에 `<앱>`/`<AI>` 뱃지를 추가하였다. 학교급 설정이 스킬 실행 결과에 자동 반영되며, 기본 테마가 다크모드로 변경되었다.

이후 패치에서 HTML 앱 입력 필드를 앱 이름·기능 목록·추가 요청 세 항목으로 구조화하고, 외부 CDN·ES 모듈·localStorage 등을 금지하는 생성 규칙을 보강하여 앱 생성 성공률을 높였다. 기존 데이터가 있는 사용자에게도 누락된 샘플 스킬이 자동으로 추가되도록 초기화 로직을 수정하였다. 학생기록 AI 화면에서 다른 메뉴의 생성 상태가 입력 패널을 잠그던 버그를 수정하였다. 내 스킬 실행·HTML 앱 화면에 autoFocus를 추가하여 화면 전환 즉시 키보드 입력이 가능하도록 개선하고, API 키 비활성화 시 안내 배너를 표시하도록 하였다. HTML 앱 카드에 수정 버튼을 추가하고, {{teacher_name}}·{{institution}}·{{school_level}} 시스템 변수를 프롬프트 템플릿에서 사용할 수 있도록 지원하였다.

v1.10.3은 보안과 생성 결과 검토 흐름을 강화한 릴리즈이다. API 키 노출 방지, HTTPS 연결 제한, 외부 도구의 JSON·HTML 검증, sanitizer 적용으로 보안 수준을 높였다. 생성 결과 화면에 교사 검토 체크리스트를 추가하여 개인정보·과장 표현·금지 표현·최신 지침 등을 점검할 수 있게 하였고, 빠른 재작성 버튼으로 더 짧게·더 공문답게·더 따뜻하게·중복 줄이기·NEIS 다듬기 등을 바로 요청할 수 있도록 하였다. 개인정보 보호 모드를 추가하여 AI 요청 전 학생 이름을 임시 토큰으로 치환하고 응답을 받은 뒤 원래 이름으로 복원하도록 하였다. 학생 메모를 학생기록 생성 시 참고자료로 연결할 수 있게 하였다.

v1.10.4는 저장·복사 UX를 단순화한 릴리즈이다. HWPX 직접 저장 메뉴를 제거하여 HWPX 양식 채우기 경우에만 표시되도록 하고, 편집 영역 강제 포커스를 제거하였다. 저장 버튼을 하나로 통합하여 PDF·Word·HWP·HTML·MD를 선택해 저장할 수 있게 하고, 복사 버튼도 HWP/웹 복사·Excel로 복사·MD로 복사로 통합하였다. 생성 결과 히스토리를 정리하고, 이수증 수집기의 파일 수를 10개로 제한하고 재실행 시 초기화되도록 개선하였다.

v1.11.0은 API 키 없이 사용 가능한 교무 실용 기능을 대거 추가한 릴리즈이다.

**공문 보관함** — 공문 캡처 이미지(Ctrl+V 붙여넣기 포함)와 붙임문서를 앱 내에 저장·관리한다. 분류별 필터와 제목·메모 검색을 지원하며, 저장된 첨부파일은 다운로드할 수 있다. 교무행정AI 섹션에 배치하였다.

**양식 인쇄 도구** — 학교 현장에서 자주 쓰는 양식 8종(일기, 독서감상문, 편지, 독서기록장, 수업 자기평가지, 모둠 활동 기록지, 상담 기록지, 연수 등록부)을 내장하였다. 양식 선택 후 필드를 채우면 A4 미리보기가 실시간으로 반영되고, PDF 저장·인쇄로 즉시 출력할 수 있다. 교무행정AI 섹션에 배치하였다.

**스킬 고정·복제** — 내 스킬 목록에서 자주 쓰는 스킬을 상단에 고정하고(핀 아이콘), 기존 스킬을 복사본으로 복제할 수 있다. 고정된 스킬은 구분선으로 시각적으로 분리하여 표시한다.

**워크시트 재사용 편집기** — 수업AI에서 생성한 워크시트를 앱 내에 저장하고, 저장된 워크시트 탭에서 목록 조회·불러오기·PDF 저장·삭제를 지원한다.

**예산사용계획** — 나라장터 물품 검색 API를 활용해 예산 과목별(교육운영비·일반수용비·업무추진비) 물품을 탐색하고, 단가·수량을 조합하여 배정 예산 대비 잔액을 실시간으로 확인할 수 있다. 자동 0원 맞추기 기능과 CSV 내보내기를 제공한다. 교무행정AI 섹션에 배치하였다.

v1.10.5는 현장에서 발견된 세부 버그를 정리한 릴리즈이다. 데모 화면 다크모드 버그와 데모 샘플 한글 표시를 수정하고, 스킬 공유 설문 자동 입력을 보강하였으며, 주의어 감지 툴팁을 추가하였다. 공문 분석 결과의 다크모드 텍스트 가시성을 개선하고, 워크시트에서 AI가 임의로 삽입한 이미지가 깨지던 문제를 이미지 대신 텍스트로 대체하여 해결하였다. 내 스킬 사이드바 탭 클릭 시 view가 초기화되지 않던 버그를 수정하고, 한글 최적화 복사 옵션을 제거하였으며, 지출품의서의 결재란 출력을 방지하였다.

이후 추가 개선 사항으로 홈 화면 상단 레이아웃을 전면 개편하여 API 키 상태·사용자 정보·학생 정보·마지막 백업 시간을 1행 4열 카드로 배치하였다. 기존 "학생 기록" 항목은 제거하고 사용자 정보·학생 정보 입력 여부를 표시하는 방식으로 교체하였으며, 백업 완료 시 마지막 백업 시간이 홈 화면에 즉시 반영되도록 하였다. 다크모드 버그 수정 범위를 정리하여 문서 미리보기·챗봇 응답 영역에서 흰 배경 위에 텍스트가 밝게 보이던 문제를 수정하고, prose CSS 범위를 공문 분석 결과 영역(`dark-prose-area`)으로 한정하였다. 이수증 수집기 프롬프트를 개선하여 성명 추출 우선순위를 강화하고(성명을 첫 번째 열로 명시), 마크다운 표 구분선을 추가하여 파싱 안정성을 높이고 오름차순 정렬을 유지하도록 하였다.

추가로 데모 화면의 공문서 작성기 하위 샘플을 확장하였다. 기존에 없던 계획서·보고서·품의서·협의록·보도자료·메세지·공고문 샘플을 추가하여 공문서 작성기 9종 샘플을 완비하였다.

사이드바 UI도 개선하였다. 메뉴 텍스트에 `truncate`·`min-w-0` 속성을 추가하여 창 크기를 줄일 때 텍스트가 줄 바꿈되며 세로로 밀리던 문제를 해결하였다. 사이드바 최소 너비를 160px에서 200px으로, 앱 최소 창 너비를 900px에서 1000px로 상향하였다. 학교급 변경 버튼의 색상을 indigo 계열에서 slate 계열로 변경하여 학생기록AI 영역과의 색상 겹침을 해소하였다.

사용 방법·도움말 화면도 업데이트하였다. 앱 전반에서 'AI스킬즈'로 혼용되던 명칭을 '내 스킬'로 통일하고, 홈 화면 앱 상태 설명 섹션과 HTML 앱 만들기 항목을 사용 방법에 추가하였다. 도움말에는 내 스킬의 주요 기능 설명을 추가하였다.

v1.11.4는 예산 작성 흐름을 단순화한 릴리즈이다. 교무행정AI의 '예산사용계획' 메뉴 이름을 '예산안작성'으로 변경하였다. 기존에는 왼쪽 입력 영역의 '예산안 만들기'로 빈 예산안 틀을 만든 뒤, 다시 상단의 '예산안 만들기' 버튼을 눌러 품목을 생성하는 2단계 구조였는데, 이를 입력 영역의 '예산안 만들기' 버튼 하나로 통합하여 예산안 틀 생성과 품목 자동 생성(AI 또는 내장 후보)이 한 번에 이루어지도록 하였다. 상단의 중복 버튼은 제거하였다. 또한 자동 생성·단가 추정 로직과 내장 품목 단가를 1만원(만원) 단위 중심으로 정돈하고, 만원 단위로 만들기 어려운 소액 소모품에 한해 천원 단위를 사용하도록 하였다. 다만 잔액을 0원에 가깝게 맞추는 채움 품목은 정밀 조정을 위해 기존의 소액 단위를 그대로 유지한다.

같은 릴리즈에서 '0원 맞추기' 기능을 변경 최소화 방식으로 재구현하였다. 사용자가 직접 수정하거나 잠근 행은 그대로 고정한 채, 나머지 행은 현재 수량을 최대한 유지하면서 단가가 큰 품목 위주로 수량을 최소한만 조정해 전체 예산 총액의 잔액을 0원에 맞춘다. 품목마다 최소·최대 수량을 지정하면 그 범위 안에서만 조정하며, 정확히 0이 되지 않을 때는 잔액이 초과되지 않는 선에서 0에 최대한 가깝게 줄이고 남는 끝자리 금액은 소액 품목으로 채운다. 또한 하위 항목을 가진 부모(묶음) 행의 규격 칸에 표시되던 '묶음' 문구를 제거하여 표를 더 깔끔하게 정리하였다. 과목별 비율을 따로 입력하지 않아도 예산안을 만들 수 있도록 하였으며, 비율이 비어 있을 때는 업무추진비를 총 예산의 3%로 배정하고 나머지를 교육운영비·일반운영비에 자동 배분한다.

또한 그동안 안내 문구로만 약속돼 있고 실제로는 빠져 있던 '인터넷 가격 조회' 기능을 구현하였다. 예산안 화면 위쪽에 검색 패널을 추가하여, 입력해 둔 나라장터·네이버 쇼핑 키로 키워드를 검색하면 실제 상품명·규격·단가·출처 링크를 목록으로 보여주고, 항목을 누르면 선택한 과목에 품목으로 바로 추가한다(단가와 출처가 자동 입력됨).

또한 공문서 작성기의 미리보기에서 한글 제목과 본문이 글자 중간에서 어색하게 줄바꿈되던 문제를, 예시 미리보기·생성 결과·저장(PDF·HTML·Word) 문서 모두에 `word-break: keep-all`(어절 단위 줄바꿈)을 적용하여 해결하였다. 아울러 계획서 예시에 포함돼 있던 폐지 사업 'AI 디지털교과서(AIDT)' 관련 문구를 제거하였다.

v1.11.5는 예산안작성의 표를 과목 중심 트리로 개편한 릴리즈이다. 교육운영비·일반운영비·업무추진비 과목을 트리의 1단계 루트 행으로 두어, 모두 접으면 과목 세 줄만 보이고 펼치면 '과목 > 품목'의 2단계로 표시되며 필요 시 3단계까지 직접 구성할 수 있도록 하였다. 자동으로 생기던 '세부' 중간 단계를 없앴고, 과목과 상위(하위 항목을 가진) 행은 규격·단가·수량 칸을 비우고 소계만 하위 합계로 표시한다. '모두 접기/펼치기'와 '과목별 정렬' 버튼을 추가하였으며, 산만하던 행 추가 방식을 정리해 각 과목 행의 '+ 품목' 버튼으로 품목을 추가하도록 단순화하였다(품목 행에는 세부 항목 추가 아이콘만 둔다). 인터넷 가격 조회로 추가한 품목은 해당 과목 맨 위에 삽입되고, 검색 결과에 마우스를 올리면 상품 이미지를 미리보기로 보여준다(외부 이미지는 data URI로 변환해 CSP를 우회). CSV로 내려받을 때도 화면에서 보이는 트리 모양(과목·들여쓰기·상위 행 빈칸)과 동일하게 저장·복원되도록 하였다.

## 6. 향후 개선 방향

- HWPX 관련 기능은 안정적인 문서 구조 보존 방식이 확보된 뒤 정식 기능으로 전환한다.
- 업무추출 결과는 업무 종류별로 캘린더 제목과 날짜를 더 정밀하게 추출하도록 개선한다.
- 학생 정보가 반영되는 기능은 계속해서 명시적 사용자 동작을 기준으로 제한한다.
- 상담 녹음 분석(Gemini 오디오 입력)은 개인정보와 API tier 정책 검토 후 도입을 검토한다.
- 수업 참여방(교사 PC 로컬 서버 + QR 입장) 구조는 교사망·학생망 분리 환경 호환성 검토 후 도입을 검토한다.
- 릴리즈는 main 브랜치 push 시 GitHub Actions가 Windows EXE를 자동 빌드·배포한다.
