⬇ Windows용 다운로드

최신 버전 v1.28.5 사용 가능

필요한 기능은 AI 스킬로 계속 확장됩니다.

업무 자료는 내 컴퓨터에 저장 무료 API 키로 시작 가능 Windows 10 / 11 설치 없는 포터블 실행

주요 기능

학생 기록, 교무행정, 수업 준비 세 영역과 직접 만드는 스킬로 나뉩니다.

📄

교무행정AI

공문서·계획서·연수자료 등 문서 10종을 작성하고, 공문을 요약해 해야 할 일을 뽑습니다. 교무행정 챗봇도 있습니다.

🖥️

수업자료AI

슬라이드, 학습지, 퀴즈, 수업계획서를 만듭니다. 수업 중에는 QR 채팅방과 럭키드로우를 쓸 수 있습니다.

🎓

학생기록AI

행동특성, 교과 세특, 스포츠클럽, 창의적 체험활동 문구 초안을 만들고, 수업관찰·상담일지·학급경영일지를 정리합니다.

🧩

내 스킬

자주 쓰는 AI 작업을 스킬로 저장합니다. 위저드, 대화형, HTML 앱 세 방식으로 만들 수 있고, 스킬마켓에서 서로 공유합니다.

작성 중 내용 자동 저장 다크 모드 명단의 학생 이름 가림(개인정보 보호 모드) HWPX · PDF · Word 저장 QR 채팅방

화면으로 보는 EduNote

공문과 계획서, 예산, 학생 기록, 수업 활동지와 스킬 공유까지. 실제로 쓰는 화면을 살펴보세요.

예시 자료를 넣어 캡처한 실제 앱 화면입니다. 학생 정보는 가명이며, 활동지는 화면 소개용 예시 자료입니다. 이미지를 누르면 새 탭에서 크게 볼 수 있습니다.

다운로드

설치 없이 실행 파일 하나로 시작합니다.

  • 1
    다운로드 후 실행설치 프로그램 없이 .exe 파일을 실행하면 열립니다.
  • 2
    무료 Gemini API 키 등록Google AI Studio에서 발급받아 앱의 설정 화면에 붙여넣습니다. 무료 등급 키로 보낸 내용은 Google 서비스 개선에 쓰일 수 있으므로, 상담·관찰 기록처럼 민감한 작업에는 결제를 연결한 유료 등급 키를 권장합니다.
  • 3
    사용 시작메뉴에서 만들 항목을 고르고 내용을 입력하면 초안이 생성됩니다.
