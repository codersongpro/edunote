# EduNote 사용자 매뉴얼

작성 기준: 2026년 6월 13일
대상 버전: EduNote v1.15.0
대상 사용자: 컴퓨터 사용이 익숙하지 않은 교사 및 처음 사용하는 사용자

## 1. EduNote란?

EduNote는 교사가 학교 업무를 조금 더 빠르고 편하게 처리할 수 있도록 돕는 Windows용 프로그램입니다.

학생기록 작성, 공문서·계획서·보고서 작성, 수업자료 생성, 공문 업무추출, 자료 관리 등을 한 프로그램 안에서 할 수 있습니다.

## 2. EduNote로 할 수 있는 일

| 구분 | 할 수 있는 일 |
| --- | --- |
| 학생기록AI | 생기부도우미(행발·교과세특·스포츠클럽·창체), 우리반기록(수업관찰기록·상담일지·학급경영일지·학생 메모 보드), 학생기록AI 챗봇 |
| 교무행정AI | 공문서(9종), 공문요약·업무추출, 공문 할일, 공문 보관함, 양식 인쇄, 예산안작성, 간단 번역, 교무행정AI 챗봇 |
| 수업자료AI | 수업 슬라이드, 워크시트, 퀴즈(객관식·주관식·OX), 수업 계획서, QR 메이커, 럭키드로우, 채팅방, 나만의 자료실 |
| 내 스킬 | 나만의 AI 스킬 만들기(위저드·대화형·HTML 앱), 스킬 실행, 스킬 공유 및 가져오기 |
| 백업 | 다른 컴퓨터에서도 자료를 이어 쓸 수 있도록 전체 자료 백업 |

## 3. 처음 사용하기 전에 알아둘 점

EduNote는 결과물을 자동으로 만들어 주지만, 최종 문서는 반드시 사용자가 직접 확인해야 합니다.

특히 학생기록, 공문서, 가정통신문, 보고서처럼 공식적으로 사용되는 문서는 사실관계, 이름, 날짜, 장소, 금액, 학교명 등을 꼭 검토해야 합니다.

EduNote를 실행하면 먼저 사용 동의 온보딩 화면이 열립니다. 사용 동의 내용을 확인한 뒤 체크하면 다음 단계로 진행하거나 `동의하고 창 닫기`로 바로 앱을 시작할 수 있습니다. 이전에 입력한 API 키, 이름, 소속기관, 학교급, 담당 학년/반 정보가 있으면 온보딩 화면에 기존 상태가 반영됩니다. 단, 저장된 API 키 원문은 보안상 다시 표시하지 않습니다.

## 4. 설치 및 실행 방법

### 4.1 다운로드

1. 아래 주소에서 최신 릴리즈 페이지로 이동합니다.

   **https://github.com/codersongpro/edunote/releases**

2. 페이지에서 `edunote_버전_portable.exe` 파일을 클릭하여 다운로드합니다.
3. 다운로드한 파일을 원하는 폴더에 둡니다.
4. 설치 과정 없이 EXE 파일을 실행합니다.

### 4.2 Windows 보안 경고가 나타날 때

처음 실행할 때 Windows에서 파란색 또는 주황색 보안 경고 화면이 나타날 수 있습니다. 개인 개발자가 배포하는 프로그램에서 흔히 발생하는 정상적인 현상입니다.

**파란색 화면("Windows에서 PC를 보호했습니다")이 나타날 때:**

1. `추가 정보`를 클릭합니다.
2. 하단에 `실행` 버튼이 나타나면 클릭합니다.
3. EduNote가 열리면 정상입니다.

**주황색 화면(SmartScreen 경고)이 나타날 때:**

1. `자세히` 또는 `추가 정보`를 클릭합니다.
2. `어쨌든 실행`을 클릭합니다.

**백신 프로그램이 차단할 때:**

일부 백신 프로그램이 서명되지 않은 EXE 파일을 일시적으로 차단할 수 있습니다.

1. 백신 프로그램의 격리함(격리 보관함)을 열어 EduNote 파일을 확인합니다.
2. 안전한 파일로 등록하거나 복원합니다.
3. EduNote 파일이 있는 폴더를 백신 프로그램의 예외(제외) 목록에 추가하면 이후 반복을 막을 수 있습니다.

## 5. Gemini API 키 설정

EduNote의 AI 기능을 사용하려면 Gemini API 키가 필요합니다.

### 5.1 API 키 받기

1. 인터넷 브라우저를 엽니다.
2. [aistudio.google.com](https://aistudio.google.com)에 접속합니다.
3. Google 계정으로 로그인합니다.
4. 왼쪽 메뉴에서 `API 키` 또는 `Get API key`를 찾습니다.
5. `API 키 만들기` 또는 `Create API key`를 누릅니다.
6. 생성된 키를 복사합니다.

> 키 만들기가 거부되면서 "Google Cloud에서 만들기" 안내가 나오는 경우가 있습니다. 이때의 대응 방법은 아래 [17.5 API 키 발급이 거부되고 'Google Cloud에서 만들기' 안내가 나올 때](#175-api-키-발급이-거부되고-google-cloud에서-만들기-안내가-나올-때)를 참고하세요.

> 온보딩 2단계, 설정 화면, 사용 방법 화면의 API 키 발급 안내에서 `키 발급 도움받기 (영상)` 버튼을 누르면 발급 과정을 화면으로 보여주는 안내 영상을 바로 열 수 있습니다.

### 5.2 EduNote에 API 키 넣기

1. EduNote 왼쪽 메뉴에서 `설정`을 누릅니다.
2. `API 키 설정` 칸에 복사한 키를 붙여넣습니다.
3. `API 키 저장`을 누릅니다.
4. 왼쪽 아래에 `API 사용 가능!`이 보이면 사용할 준비가 된 것입니다.

> 저장한 API 키는 인터넷으로 전송되지 않고 이 컴퓨터의 앱 설정 파일에만 저장됩니다. 다만 설정 파일 자체는 암호화되지 않으므로, 다른 사람과 함께 쓰는 컴퓨터에서는 사용 후 설정 화면에서 `저장된 API 키 삭제`를 활용하는 것이 안전합니다. API 키는 자료 백업 파일에 포함되지 않습니다.

### 5.3 무료 키와 유료 키

| 구분 | 내용 |
| --- | --- |
| 무료 키 | 기본 제공. 분당 요청 횟수 제한이 있어 연속 사용 시 일시 제한될 수 있음 |
| 유료 키 | Google Cloud 결제 계정 연동 키. 더 빠른 모델과 높은 사용 한도 제공 |

설정 화면에서 사용 중인 API 키의 등급(무료/유료)을 선택할 수 있습니다.

### 5.4 API 상태 표시 이해하기

| 표시 문구 | 위치 | 의미 | 해야 할 일 |
| --- | --- | --- | --- |
| API 사용 가능! | 왼쪽 하단 | AI 생성 가능 상태 | 그대로 사용 |
| API 키 저장됨 · 사용 확인 필요 | 왼쪽 하단 | 키는 저장됐지만 아직 확인이 필요함 | 설정 화면에서 키 확인 |
| API 일시 제한 · 키 변경/잠시 후 재시도 | 왼쪽 하단 | 요청이 많거나 한도 문제로 잠시 생성 불가 | 잠시 기다리거나 다른 키 사용 |
| API 키를 설정해 주세요 | 왼쪽 하단 | API 키가 없음 | 설정에서 API 키 입력 |
| API 키를 설정하거나 확인해 주세요 | 스킬 실행·HTML 앱 화면 상단 배너 | 키가 없거나 아직 확인되지 않은 상태에서 내 스킬을 열었을 때 | 배너 안의 `설정 바로가기` 클릭 |
| API가 일시적으로 제한되었습니다 | 스킬 실행·HTML 앱 화면 상단 배너 | 요청 초과 또는 오류로 잠시 제한된 상태 | 잠시 기다리거나 API 키 변경 |

`API 일시 제한` 문구가 왼쪽 아래에서 깜빡이면 마우스를 올려 설명을 확인할 수 있습니다. 내 스킬 실행·HTML 앱 만들기 화면에서는 API 상태 배너가 입력 영역 바로 위에 표시되어 더 눈에 잘 띕니다.

### 5.5 화면 테마 설정

EduNote는 처음 실행 시 **다크모드**가 기본으로 적용됩니다. 오른쪽 상단의 달/해 아이콘을 클릭하면 라이트모드와 다크모드를 전환할 수 있습니다. 변경된 설정은 다음 실행 시에도 유지됩니다.

> v1.13.0부터 화면 전체의 색상과 글꼴이 베이지·차콜 계열의 따뜻한 톤으로 새로 단장되었습니다. 라이트·다크 모드 전환 방법과 화면 구성, 사용 방법은 이전과 동일합니다.

> 참고: API 키 안내·학교급 선택 같은 안내 창은 키보드의 `Esc` 키로도 닫을 수 있습니다.

## 6. 화면 구조 이해하기

EduNote는 왼쪽 메뉴와 오른쪽 작업 화면으로 구성되어 있습니다.

```text
왼쪽 메뉴
├─ 홈
├─ 사용 방법
├─ 도움말 / 정보
├─ 설정
│
├─ [교무행정AI]
│  ├─ 교무행정AI 챗봇
│  ├─ 공문요약·업무추출
│  ├─ 공문 할일
│  ├─ 문서작성기 (공문서·계획서·보고서·품의서·회의록·홍보자료·가정통신문·메세지·공고문)
│  ├─ 공문 보관함
│  ├─ 양식 인쇄
│  ├─ 예산안작성
│  └─ 간단 번역
│
├─ [수업자료AI]
│  ├─ 수업자료 생성
│  ├─ 수업 도구
│  │  ├─ QR 메이커
│  │  ├─ 럭키드로우
│  │  └─ 채팅방
│  └─ 나만의 자료실
│
├─ [학생기록AI]
│  ├─ 학생기록AI 챗봇
│  ├─ 생기부도우미
│  │  ├─ 행발생성
│  │  ├─ 교과 세특 생성
│  │  ├─ 학교스포츠클럽
│  │  └─ 창체 특기사항
│  └─ 우리반기록
│     ├─ 수업관찰기록
│     ├─ 상담일지
│     ├─ 학급경영일지
│     └─ 학생 메모 보드
│
└─ [내 스킬]
   ├─ 내 스킬 (스킬 목록, 실행, 수정, 공유)
   └─ 스킬마켓 (마켓에서 가져오기)
```

왼쪽 메뉴 하단에는 **Demo** 버튼이 있습니다. 누르면 별도 창이 열리고 각 기능에서 사용할 수 있는 샘플 입력값을 복사해 바로 붙여넣을 수 있습니다. 각 샘플을 펼치면 **무엇을 하는 기능인지 설명**, **사용 순서**, **기대 결과**가 함께 표시되어, 기능을 처음 보는 분도 따라 하기 쉽습니다. 공문요약·업무추출 샘플에는 일정, 마감일, 참고 웹사이트 주소가 함께 들어 있어 요약과 업무 추출 흐름을 한 번에 시연할 수 있습니다.

대부분의 주요 화면 상단에 **튜토리얼** 버튼이 있습니다. 누르면 실제 화면 위에서 입력칸·버튼을 단계별로 짚어 주는 따라 하기 안내가 시작됩니다. `다음`/`이전`으로 단계를 넘기고 `건너뛰기`로 닫을 수 있습니다. 튜토리얼이 제공되는 메뉴: 문서작성기, 수업자료 생성, 예산안작성, 학생기록AI 챗봇, 교무행정AI 챗봇, 공문요약·업무추출, 수업관찰기록(우리반기록), 수업 도구(QR·럭키드로우·채팅방), AI스킬즈, HTML 앱 만들기, 공문 보관함, 양식 인쇄, 학생 메모 보드.

왼쪽 메뉴에서 원하는 기능을 누르면 오른쪽 화면이 바뀝니다.

각 섹션 내 메뉴 항목은 드래그하여 원하는 순서로 변경할 수 있습니다.

공문서 9종, 생기부도우미 세부 메뉴, 우리반기록, QR 메이커·럭키드로우, 내 스킬·스킬마켓처럼 한 기능 안의 하위 메뉴는 오른쪽 작업 화면 상단의 가로 탭에서 선택합니다. 생성 중인 작업이 있으면 다른 메뉴로 이동해도 상단 탭이나 접힌 사이드바 아이콘에 진행률이 표시됩니다.

왼쪽 사이드바를 접으면 얇은 아이콘 바가 남습니다. 이 상태에서도 홈, 설정, 교무행정AI, 공문요약, 문서작성기, 수업자료AI, 학생기록AI, AI 스킬즈, 사용 방법, 도움말 / 정보로 바로 이동할 수 있습니다.

## 7. EduNote의 기본 사용 흐름

대부분의 기능은 아래 순서로 사용합니다.

1. 왼쪽 메뉴에서 원하는 기능을 선택합니다.
2. 필요한 내용을 입력합니다.
3. `생성` 버튼을 누릅니다.
4. 결과가 나오면 내용을 확인합니다.
5. 필요한 부분을 수정합니다.
6. 복사하거나 PDF, HTML, 문서 파일 등으로 저장합니다.

> 참고: 사용 방법 화면 상단의 `에듀노트 전체 사용법 보기 (영상)` 버튼을 누르면 에듀노트 전체 사용법을 보여주는 안내 영상을 바로 열 수 있습니다.

## 8. 학생기록 AI 사용 방법

학생기록 AI는 학생 관찰 내용을 바탕으로 학교생활기록부에 참고할 문장을 만드는 기능입니다.

### 8.1 학생기록AI 챗봇

생활기록부 기재 방법을 물어볼 수 있습니다. 학교급을 선택한 상태에서 기재요령 관련 질문을 입력하면 답변을 제공합니다. 화면 상단의 **튜토리얼** 버튼을 누르면 자주 묻는 질문 버튼·입력창·답변 영역 사용법을 단계별로 안내합니다.

### 8.2 행발생성 (행동특성 및 종합의견)

1. `학생기록AI`에서 `행발생성`을 누릅니다.
2. 학생 이름을 입력합니다.
3. 긍정적인 특성 태그와 보완이 필요한 부분을 선택합니다.
4. 추가로 참고할 내용을 입력합니다.
5. 생성 버튼을 누릅니다.
6. 결과 문장을 확인하고 학생에게 맞게 수정합니다.

### 8.3 교과 세특 생성

1. `교과 세특 생성`을 누릅니다.
2. 교과, 학생 이름, 성취수준, 활동 내용, 관찰 내용을 입력합니다.
3. 필요한 경우 평가계획서나 수행평가 자료를 업로드합니다.
4. 생성 버튼을 누릅니다.
5. 학생의 실제 활동과 맞는지 확인합니다.

### 8.4 학교스포츠클럽 특기사항 생성

1. `학교스포츠클럽`을 누릅니다.
2. 학생 이름, 종목, 관찰 내용을 입력합니다.
3. 생성 버튼을 누릅니다.

### 8.5 창체 특기사항 생성

1. `창체 특기사항`을 누릅니다.
2. 활동 영역, 활동 관련 태그, 추가 관찰 내용을 선택·입력합니다.
3. 생성 버튼을 누릅니다.

### 8.6 상담일지 생성

1. `상담일지`를 누릅니다.
2. 상담 관련 내용을 입력합니다.
3. 생성 버튼을 누릅니다.

### 8.7 학급경영일지 생성

1. `학급경영일지`를 누릅니다.
2. 학급경영 내용을 입력합니다.
3. 생성 버튼을 누릅니다.

### 8.8 학생기록 사용 시 주의사항

- 학생 이름, 성적, 민감한 개인정보는 꼭 필요한 경우에만 입력합니다.
- 생성된 문장은 그대로 쓰지 말고 반드시 검토합니다.
- 과장된 표현이나 실제와 다른 내용은 삭제합니다.

## 9. 교무행정 AI 사용 방법

교무행정 AI는 학교 업무 문서를 작성하거나 공문 업무를 정리하는 기능입니다.

### 9.1 문서작성기

왼쪽 메뉴에서 `문서작성기`를 선택하면 탭 방식으로 9가지 문서 유형을 선택할 수 있습니다.

| 문서 유형 | 설명 |
| --- | --- |
| 공문서 | 수신·경유·제목·본문·붙임 형식의 시행문 |
| 계획서 | 추진배경, 목적, 세부추진계획, 소요예산, 기대효과 |
| 보고서 | 추진개요, 추진실적, 운영결과, 예산정산, 성과 및 제언 |
| 품의서 | 지출품의서 형식 |
| 회의록 | 일시, 장소, 참석자, 안건, 발언 내용 |
| 홍보자료 | 보도자료 및 SNS 홍보 요약 |
| 가정통신문 | 제목, 인사말, 안내 내용, 맺음말 |
| 문자&소통메시지 | SMS/LMS 형식 |
| 공고문 | 공고번호, 제목, 내용, 접수기간, 문의처 |

**공문서·품의서**: `~합니다.`, `~입니다.`, `~습니다.` 형태의 합쇼체로 작성됩니다.

**계획서·보고서**: 개조식(`가.`, `나.`, `다.`) 항목으로 작성됩니다. 제목은 크게, 진하게, 가운데 정렬됩니다. 표가 필요한 내용은 선이 있는 표로 생성됩니다.

**입력칸을 다 채우지 않아도 됩니다**: 제목이나 주제만 입력하고 생성해도, 비워 둔 항목(대상·일시·장소·예산 등)은 제목·주제에 어울리는 내용으로 AI가 자연스럽게 추정해 완성된 문서를 작성합니다. 생성 후 미리보기에서 실제 내용에 맞게 수정하세요. 단, 근거 법령·공문번호는 추정하지 않고 사용자가 채울 자리로 표시됩니다.

### 9.2 보고서 작성

1. `문서작성기`에서 `보고서` 탭을 선택합니다.
2. 보고서 주제, 대상, 예산/집행액, 운영 결과 요약, 추가 사항을 입력합니다.
3. 필요한 경우 참고 자료 파일을 업로드합니다.
4. 생성 버튼을 누릅니다.
5. 추진 개요, 추진 실적, 운영 결과, 예산 정산, 성과 및 제언을 확인합니다.

### 9.3 공문 업무추출

입력 패널 상단의 **튜토리얼** 버튼을 누르면 공문 붙여넣기·분석 버튼·결과 영역 사용법을 단계별로 안내합니다.

1. `공문 요약 / 업무 추출` 메뉴를 엽니다.
2. 공문 내용을 붙여넣거나 파일을 업로드합니다.
3. 분석 버튼을 누릅니다.
4. 해야 할 일, 마감, 일시, 장소, 링크를 확인합니다.
5. 필요한 경우 `할일로 저장` 버튼으로 공문 할일 목록에 추가하거나, Google Calendar에 추가합니다.

Google Calendar에 추가할 때는 분석 결과의 `마감`, `기한`, `제출`, `신청`, `접수`, `회신` 문맥에 있는 날짜를 우선 사용합니다. 공문에 행사일과 제출 마감일이 함께 있으면 캘린더 일정은 제출 마감일 기준으로 만들어지는지 확인한 뒤 저장하세요.

### 9.3.1 공문 할일

공문에서 추출한 업무를 앱 안에서 끝까지 추적하는 할일 목록입니다.

1. 공문 업무추출 결과 화면에서 `할일로 저장`을 누르면 업무 제목과 마감일이 자동으로 추출되어 저장됩니다.
2. `공문 할일` 메뉴에서 할일을 마감일 순으로 확인합니다. 마감이 가까우면 D-day 배지가 표시됩니다.
3. 완료한 일은 체크하고, 필요 없는 항목은 삭제합니다. 직접 입력해 추가할 수도 있습니다.
4. 앱을 시작할 때 마감이 3일 이내이거나 지난 할일이 있으면 알림으로 알려 줍니다.

할일 데이터는 앱 데이터 폴더에 저장되어 전체 자료 백업에 자동으로 포함됩니다.

### 9.3.2 공문 보관함

중요한 공문 원본(이미지·첨부파일)을 분류해 보관하는 기능입니다. 화면 상단의 **튜토리얼** 버튼을 누르면 공문 추가·검색·열람 방법을 단계별로 안내합니다.

1. `공문 보관함` 메뉴를 엽니다.
2. `+ 공문 추가` 버튼으로 공문 제목·분류·캡처 이미지·첨부파일을 저장합니다.
3. 검색창이나 카테고리 필터로 저장된 공문을 찾습니다.
4. 공문 카드를 열면 이미지와 붙임문서를 바로 확인하고 메모를 남길 수 있습니다.

### 9.4 교무행정AI 챗봇

교육 행정 관련 질문을 입력하면 답변을 제공합니다. 화면 상단의 **튜토리얼** 버튼을 누르면 자주 묻는 질문·입력창·답변 영역 사용법을 단계별로 안내합니다.

### 9.5 양식 인쇄

학교에서 자주 쓰는 종이 양식을 화면에서 채운 뒤 A4 PDF로 저장·인쇄하는 기능입니다. 양식 목록 화면 상단의 **튜토리얼** 버튼을 누르면 양식 선택·편집·저장 방법을 단계별로 안내합니다. Gemini API 키 없이 사용할 수 있습니다.

1. `양식 인쇄` 메뉴를 엽니다. 위쪽 탭에서 양식 분류(글쓰기 / 학급 활동 / 교무 행정)를 고릅니다.
2. 사용할 양식 카드를 누르면 왼쪽에 입력 패널, 오른쪽에 A4 미리보기가 나타납니다. 내용을 입력하면 미리보기에 바로 반영됩니다.
3. `PDF 저장·인쇄` 버튼으로 출력하고, `초기화`로 입력을 비울 수 있습니다. `미리보기`/`편집으로` 버튼으로 화면을 전환할 수 있습니다.

현재 제공하는 양식은 다음과 같습니다.

- 글쓰기: 일기, 독서감상문, 편지
- 학급 활동: 독서 기록장, 수업 자기평가지, 모둠 활동 기록지, 상담 기록지, 학급 회의록, 1인 1역할
- 교무 행정: 연수 등록부

추가로 알아두면 좋은 점:

- `학급 회의록`은 일시·사회·서기·참석 현황과 안건·협의 내용·결정 사항·건의사항을 한 장에 정리합니다.
- `1인 1역할`은 한 줄에 `역할/담당 학생` 형식으로 입력하면 표로 만들어집니다. ( `/` 로 칸을 구분합니다.)
- `연수 등록부`는 참가자 명단을 번호별 칸에 입력하고, `명단 추가` 버튼으로 20명을 넘겨 계속 추가할 수 있습니다. 명단이 길면 인쇄 시 다음 장으로 이어집니다.

### 9.6 예산안작성

학교 예산 과목(교육운영비·일반운영비·업무추진비)에 맞춰 예산안을 만들고, 배정 예산 대비 잔액을 확인하는 기능입니다.

1. `예산안작성` 메뉴를 엽니다.
2. 왼쪽 입력 영역에 예산 제목과 전체 예산(원)을 입력합니다. 입력칸의 회색 `예:` 문구를 참고해 작성하면 됩니다.
3. `과목별 비율` 또는 `일반 작성` 중 하나를 선택합니다.
   - `과목별 비율`: 교육운영비·일반운영비·업무추진비 비율과 과목별 구입 물품을 입력합니다.
   - `일반 작성`: 과목 비율 없이 구입하고자 하는 물품만 입력합니다. 이 방식에서는 예산안 표의 예산 과목 칸이 빈칸으로 표시됩니다.
4. `예산안 만들기` 버튼을 누르면 예산안 틀과 품목이 한 번에 자동으로 만들어집니다. (별도의 추가 버튼 없이 이 버튼 하나로 완료됩니다.) 이때 Gemini가 **예산 제목의 주제와 사업 목적을 먼저 분석해 그 주제에 어울리는 품목**을 만듭니다. 예를 들어 제목이 '과학 탐구'이면 제목과 무관한 일반 사무용품·다과 대신 과학 수업·실험과 관련된 품목이 들어갑니다. 과목별 비율 방식에서는 교육운영비·일반운영비·업무추진비 세 과목 모두에 가능한 한 제목 주제와 연결된 품목이 배치됩니다.
5. 과목별 비율 방식의 예산안 표는 과목(교육운영비·일반운영비·업무추진비)을 맨 위 단계로 하는 트리입니다. `모두 접기`를 누르면 과목 세 줄만, 펼치면 '과목 > 품목'으로 보이며, 품목 아래에 세부 항목을 더해 최대 3단계까지 만들 수 있습니다. 과목·상위 행은 규격·단가·수량 칸이 비어 있고 소계만 표시됩니다.
6. 품목은 각 과목 행의 `+ 품목` 버튼으로 추가합니다. 품목 행의 작은 `+` 아이콘으로는 그 아래 세부 항목을 추가할 수 있습니다. 품목명·규격·단가·수량은 직접 수정할 수 있고, 단가는 가능하면 만원 단위로 제시됩니다. `과목별 정렬` 버튼으로 같은 과목끼리 다시 정렬할 수 있습니다.
7. `0원 맞추기` 버튼을 누르면, 직접 수정한 행은 그대로 두고 나머지 행의 수량을 조정해 잔액을 0원으로 맞춰 줍니다. (정확히 0이 되는 조합이 없으면 잔액을 0에 가장 가깝게 줄여 줍니다.) 최소·최대 수량은 필요한 경우에만 입력하면 되고, 입력한 경우에는 그 범위 안에서만 조정합니다.
8. 예산안 표 위쪽의 `인터넷 가격 조회로 품목 추가`에서 과목을 고르고 키워드(예: 태블릿, 복사용지)를 검색하면 실제 상품과 단가가 목록으로 나옵니다. 항목에 마우스를 올리면 상품 이미지가 미리보기로 표시되고, `추가`를 누르면 그 과목 맨 위에 품목으로 들어갑니다. (이 기능은 인터넷 가격 조회 또는 나라장터 키를 저장했을 때 사용할 수 있습니다.)
9. 저장 버튼을 누르면 예산안과 입력값이 저장되고, 저장된 계획 목록에는 저장 날짜와 시간이 표시됩니다. 앱을 다시 실행해도 저장한 예산안을 이어서 볼 수 있습니다.
10. `CSV 다운로드`로 내보내면 화면에서 보이는 트리 모양 그대로 저장되며, `CSV 불러오기`로 다시 불러올 수 있습니다.
11. 예산안이 만들어지면 기존 생성 완료 효과음과 같은 소리가 납니다.

> 인터넷 가격 조회(나라장터·쇼핑 검색) 키는 선택 입력입니다. 입력하지 않아도 예산안을 만들 수 있고, 입력하면 실제 검색 단가를 참고하거나 위 검색 패널로 직접 품목을 조회·추가할 수 있습니다.
>
> 저장한 Client Secret은 보안을 위해 화면에 다시 표시되지 않습니다. 한 번 저장하면 입력칸에 `Client Secret 저장됨 (변경할 때만 입력)`이라고 안내되며, 값을 바꿀 때만 새로 입력하면 됩니다. 입력칸을 비워 두고 저장해도 기존에 저장된 Secret은 지워지지 않습니다.

### 9.7 간단 번역

학부모 안내 문구, 문자, 알림장 내용을 빠르게 번역하는 도구입니다.

1. `간단 번역` 메뉴를 엽니다.
2. 번역 방향을 선택합니다: `한국어 → 외국어` 또는 `외국어 → 한국어`.
3. 한국어 → 외국어일 때는 대상 언어를 선택합니다. (영어, 중국어(간체), 일본어, 베트남어, 필리핀어(타갈로그), 러시아어, 우즈베크어, 몽골어, 태국어, 캄보디아어(크메르), 인도네시아어, 네팔어, 미얀마어)
4. 왼쪽에 원문을 입력하고 `번역`을 누르면 오른쪽에 번역문이 표시됩니다. `복사` 버튼으로 바로 복사할 수 있습니다.

### 9.8 사이드 패널 접기

각 기능 화면의 왼쪽 입력 패널이나 학생 목록 패널은 접고 펼칠 수 있습니다.

- 메인 사이드바, 예산안작성, 공문 요약, 문서작성기, 양식 인쇄, 수업자료 생성, 내 도구 실행 화면에서 같은 모양의 패널 접기 버튼을 사용합니다.
- 행동발달, 스포츠클럽, 교과 세특, 창체 화면의 학생 목록 패널도 같은 방식으로 접고 펼칠 수 있습니다.
- 패널을 접으면 얇은 바와 펼치기 버튼만 남아 결과 화면을 더 넓게 볼 수 있습니다.

## 10. 수업자료 AI 사용 방법

수업자료 AI는 수업에 바로 쓸 수 있는 자료를 만드는 기능입니다.

수업자료는 사용자가 여러 장을 특별히 요청하지 않으면 A4 한 장을 기준으로 구성됩니다. 내용이 길어질 때는 문항, 표, 활동 단위가 중간에 잘리지 않도록 다음 장으로 넘어가게 설계되어 있습니다.

### 10.1 수업자료 생성 기본 순서

1. `수업자료 생성`을 누릅니다.
2. 학년, 교과, 단원, 주제를 입력합니다.
3. 만들 자료 유형을 선택합니다.
4. 생성 버튼을 누릅니다.

저장 가능 형식: PDF, MD, TXT

`전체 이미지 생성`은 현재 구현중으로 표시됩니다. 사용 가능한 저장 버튼이 먼저 보이도록 구현중 버튼은 오른쪽에 배치되어 있습니다.

### 10.3 워크시트와 평가지

1. 워크시트 또는 평가지 유형을 선택합니다.
2. 문항 수와 점수 표시 여부를 설정합니다.
3. 생성 버튼을 누릅니다.
4. 결과를 PDF 또는 HTML로 저장합니다.

특별한 요청이 없으면 A4 한 장 기준으로 만들어집니다. 문항 수가 많거나 추가 설명이 길면 활동 단위가 중간에 잘리지 않는 지점에서 다음 장으로 이어질 수 있습니다.

- **주관식** — 단답형 입력 후 확인 버튼으로 채점
- **OX 퀴즈** — 참/거짓 판단

원하는 유형을 하나 또는 여러 개 체크해서 혼합 출제할 수 있습니다.

생성 후:
- `새 창에서 열기` 버튼으로 크롬·엣지에서 실행
- HTML 저장 가능
- PDF 저장 가능

수업 관찰 내용을 기록 형식으로 정리합니다. 화면 상단의 **튜토리얼** 버튼을 누르면 입력 항목·생성·결과 저장 방법을 단계별로 안내합니다.

1. `수업관찰기록`을 누릅니다.

### 11.1 QR 메이커

수업자료AI > 수업 도구 > QR 메이커에서 사용합니다. 탭 상단의 **튜토리얼** 버튼을 누르면 QR코드 제작·럭키드로우 사용법을 단계별로 안내합니다.

1. 공유할 링크를 입력합니다.
2. QR 코드를 생성합니다.
3. 학생들에게 화면을 보여주거나 저장해서 사용합니다.

### 11.2 럭키드로우

수업자료AI > 수업 도구 > 럭키드로우에서 사용합니다. 학생을 무작위로 뽑는 기능입니다.

사용 예:

- 발표 순서
- 칭찬 주인공

### 11.3 채팅방

수업자료AI > 수업 도구 > 채팅방에서 사용합니다. 학생이 로그인이나 별도 프로그램 설치 없이 QR코드만 스캔하면 들어올 수 있는 채팅방입니다.

처음 사용할 때는 무료 Firebase 프로젝트 연동이 한 번 필요합니다. 화면에 나오는 안내를 그대로 따라 하면 됩니다(신용카드 등록 불필요).

> 채팅방 설정 화면의 `채팅방 설정 도움받기 (영상)` 버튼을 누르면 Firebase 연동 과정을 화면으로 보여주는 안내 영상을 바로 열 수 있습니다.

1. 안내에 따라 Firebase 프로젝트를 만들고, 표시되는 설정값을 채팅방 화면에 붙여넣어 저장합니다. 이때 안내의 **Authentication → Sign-in method → 익명 사용 설정** 단계를 꼭 진행하세요. 채팅방은 익명 로그인을 사용하므로, 이 설정을 켜지 않으면 채팅방을 시작할 때 `configuration-not-found` 오류가 납니다. 또한 Firestore 데이터베이스를 만들 때 **위치(지역)는 "서울(asia-northeast3)"** 로 선택하면 메시지가 더 빠르게 오갑니다. (지역은 한 번 만들면 바꿀 수 없으니, 미국 등으로 이미 만들었다면 메시지 지연을 줄이려면 새 프로젝트로 다시 만들어야 합니다.)
2. 채팅방 제목(예: "3교시 모둠활동")을 입력한 뒤 `채팅방 시작`을 누르면 QR코드가 표시됩니다. 제목을 입력하지 않으면 무작위로 만들어진 코드로 표시됩니다.
3. 학생들이 휴대폰으로 QR코드를 스캔해 닉네임을 입력하면 채팅방에 입장합니다. 닉네임을 입력하기 전에도 화면 상단에 채팅방 제목이 표시되어 어느 반/시간 채팅방인지 바로 알 수 있습니다.
4. 텍스트와 링크를 자유롭게 주고받습니다. 교사도 같은 화면에서 함께 채팅할 수 있습니다. 메시지에 `http://`, `https://`, `www.`로 시작하는 웹 주소를 적으면 자동으로 클릭 가능한 링크가 됩니다. 화면은 내가 보낸 메시지는 오른쪽, 다른 사람이 보낸 메시지는 왼쪽에 표시되고 사람마다 말풍선 색이 다르게 구분됩니다.
5. `채팅방 종료`를 누르면(확인 후) 채팅방이 종료되고, **모든 학생 화면이 "채팅방이 종료되었습니다" 전체 화면으로 잠겨** 더 이상 참여할 수 없습니다(사실상 전원 퇴장). EduNote 창을 닫아도 자동으로 종료됩니다. 지난 채팅 기록은 계속 보관되어 다음에 다시 확인할 수 있습니다. (내가 만든 채팅방은 같은 PC에서 익명 로그인 정보가 유지되어 언제든 종료·삭제할 수 있습니다. 만약 "종료 권한이 없다"는 안내가 나오면, 그 방은 이전 설치·재설정 시점의 다른 계정으로 만들어진 것이므로 새 채팅방을 만들어 사용하세요.)
6. 종료된 채팅방 화면에서 `새 채팅방 만들기`를 누르면 곧바로 새 제목을 입력해 다음 채팅방을 시작할 수 있습니다.
7. 진행 중인 채팅방 화면이나 지난 채팅방 목록에서 `다운로드` 버튼을 누르면 대화 내용을 텍스트 파일로 저장할 수 있습니다.
8. 지난 채팅방 목록의 `삭제`(휴지통 아이콘) 버튼을 누르면 그 채팅방의 대화 내용·참여자 기록이 Firebase에서도 영구적으로 삭제됩니다(목록에서만 지워지는 것이 아니라 실제 데이터가 사라지므로, 삭제 후에는 되돌릴 수 없습니다). 이 기능을 쓰려면 Firebase 보안 규칙을 최신 버전으로 다시 게시해야 합니다(아래 "문제 해결" 참고).
9. Firebase 연동을 이미 마친 경우 화면에 "채팅방 설정이 완료되었습니다" 안내가 보입니다. 설정값을 바꿔야 하면 `다시 설정하기`를 눌러 같은 화면에서 다시 입력할 수 있습니다.
10. 채팅방 화면에 **참여자 목록**이 표시됩니다. 닉네임 옆 초록 점은 "접속 중", 회색 점은 "접속 끊김"을 의미합니다.
11. 참여자 목록에서 학생 이름(칩)을 누르면 그 학생에게만 보이는 **귓속말**을 보낼 수 있습니다. 여러 학생에게 동시에 보내고 싶으면 칩을 여러 개 눌러 다중 선택하면 됩니다(선택된 칩은 보라색으로 표시됩니다). 선택한 칩을 다시 누르면 그 학생만 대상에서 빠지고, 전부 해제하면 다시 전체 공개 메시지를 보냅니다. 귓속말 메시지는 다른 메시지와 구분되도록 보라색 말풍선으로 표시되며 "🔒 귓속말 → 닉네임" 표시가 붙습니다.
12. 학생이 같은 기기(같은 브라우저)에서 채팅방 탭을 두 개 이상 열면, 나중에 연 탭은 "이미 이 기기에서 접속해 있습니다" 안내와 함께 입장이 막힙니다. 기존 탭을 닫으면 다른 탭에서 새로고침해 다시 입장할 수 있습니다. (서로 다른 브라우저나 다른 기기에서 접속하는 것은 막을 수 없습니다.)
13. 메시지 옆 📌 아이콘을 누르면 그 메시지가 **공지**로 채팅창 맨 위에 고정되어 교사·학생 모두에게 항상 보입니다. 공지 옆 ✕ 버튼으로 해제할 수 있습니다. 귓속말 메시지는 공지로 고정할 수 없습니다(모두에게 보이게 되면 비공개가 깨지기 때문입니다).

> 모바일 안내: 태블릿·스마트폰으로 채팅방에 참여할 때 입력창과 글씨가 크게 보이도록 개선되었습니다. 입력창은 화면 아래에 항상 고정되어 있어 스크롤하지 않고도 바로 메시지를 입력할 수 있습니다.

> 안전 안내: 채팅방은 방 코드(QR)를 정확히 아는 사람만 들어올 수 있도록 설정되어 있습니다. QR코드나 접속 주소를 외부에 공유하지 마세요. 지난 채팅방 목록은 채팅방을 만든 그 PC에 기록되므로, 다른 PC에서는 목록이 보이지 않을 수 있습니다(채팅 내용 자체는 Firebase에 그대로 보관됩니다).
> 이 업데이트로 학생 화면이 배경에서 자동으로 "익명 인증"을 거치게 되어, 귓속말이 실제로 해당 학생과 교사에게만 전달되도록 Firebase 쪽에서도 차단됩니다. 학생이 추가로 해야 할 일은 없습니다(닉네임 입력은 그대로입니다).
> 문제 해결: 채팅방을 시작할 때 "Firebase 콘솔에서 익명 로그인이 켜져 있지 않습니다"(또는 `configuration-not-found`) 오류가 보이면, Firebase 콘솔의 해당 프로젝트에서 **Authentication → 시작하기 → Sign-in method 탭 → 익명**을 사용 설정으로 켜고 저장한 뒤 다시 시도하세요.
> 문제 해결: 채팅방 삭제 시 "권한이 없습니다"(또는 `permission-denied`) 오류가 보이면, Firebase 보안 규칙이 예전 버전으로 남아 있는 경우입니다. 채팅방 설정 화면의 `규칙 복사` 버튼으로 최신 보안 규칙을 복사해 Firebase 콘솔의 Firestore Database → 규칙 탭에 붙여넣고 다시 게시한 뒤 시도하세요. 학생에게 교사 메시지(공개 메시지·귓속말)가 보이지 않는 문제도 같은 원인일 수 있으니, 보안 규칙을 다시 게시했는지 확인하세요.

### 11.4 나만의 자료실

수업 자료 링크나 웹페이지를 저장해 두는 공간입니다.

URL을 입력하면 YouTube 썸네일·제목, 웹페이지 대표 이미지·제목을 자동으로 가져옵니다.

1. `새 자료 추가`를 누릅니다.
2. YouTube 주소 또는 웹페이지 주소를 입력합니다.
3. 제목·썸네일이 자동으로 채워지면 확인합니다. (직접 수정도 가능)
4. 분류(카테고리)를 선택하고 저장합니다.
5. 나중에 검색하거나 분류별로 다시 찾습니다.

> 이미 등록한 자료의 분류를 바꾸거나 새 분류를 만들고 싶다면, 자료 카드에 있는 분류 태그를 눌러 보세요. 드롭다운 맨 아래의 입력란에 새 주제 이름을 적고 `추가`를 누르면 그 자리에서 새 주제가 만들어지고 바로 적용됩니다.

### 11.5 학생 메모 보드

학생 관련 메모를 기록하고 나중에 찾아볼 수 있습니다. 화면 상단의 **튜토리얼** 버튼을 누르면 메모 추가·검색·필터 사용법을 단계별로 안내합니다.

입력 항목:
- 제목
- 학생 이름 (여러 명 선택 가능)
- 내용

학생 이름이나 키워드로 필터링하여 검색할 수 있습니다.

## 12. 내 스킬 사용 방법

내 스킬은 자주 사용하는 AI 작업을 코드 없이 직접 만들어 사용하는 기능입니다. 크게 세 가지 방법으로 나만의 AI 스킬을 만들 수 있습니다. 화면 상단의 **튜토리얼** 버튼을 누르면 스킬 목록 관리·스킬 마켓·새 스킬 만들기 방법을 단계별로 안내합니다.

### 12.1 스킬 만들기 — 위저드

AI 스킬을 단계별로 만드는 방법입니다.

1. 왼쪽 메뉴에서 `내 스킬`을 누릅니다.
2. `새 스킬 만들기`를 누릅니다.
3. **1단계 — 기본 정보**: 스킬 이름, 설명, 카테고리를 입력합니다.
4. **2단계 — 입력 필드 구성**: AI에게 전달할 항목을 추가합니다.
   - 한 줄 텍스트 / 여러 줄 텍스트 / 파일 첨부 중 선택
5. **3단계 — 프롬프트 작성**: AI에게 보낼 지시문을 작성합니다.
   - 위쪽 칩을 클릭하면 입력 필드가 자동으로 삽입됩니다.
   - `AI 도움받기` 버튼을 누르면 프롬프트 초안을 자동으로 작성해 줍니다.
   - 참고 양식 파일을 첨부하면 해당 양식에 맞게 프롬프트를 작성해 줍니다.
   - `프롬프트 진단` 버튼을 누르면 AI가 작성된 프롬프트를 분석해 점수와 개선 제안을 보여줍니다.
     - 이슈는 심각도(높음/중간/낮음)에 따라 색상으로 구분됩니다.
     - `개선안 적용` 버튼을 누르면 개선된 프롬프트가 한 번에 적용됩니다.
6. **4단계 — 테스트 실행**: 저장하기 전에 샘플 값을 입력하고 결과를 미리 확인합니다.
   - 입력 필드에 예시 값을 넣고 `테스트 실행`을 누릅니다.
   - 오른쪽에 AI 결과가 표시됩니다. 프롬프트를 수정하고 다시 실행해 볼 수 있습니다.
   - 교사 이름 등 전역 변수(`{{teacher_name}}` 등)는 실제 실행 시 자동으로 채워집니다.
7. `저장`을 누르면 내 스킬 목록에 추가됩니다.

### 12.2 스킬 만들기 — 대화형

AI와 대화하면서 스킬이나 HTML 앱을 자동으로 만드는 방법입니다.

1. `대화로 만들기`를 누릅니다.
2. 먼저 만들 결과물 형태를 선택합니다.
   - `AI 스킬` — 입력값을 받아 AI가 글·표 등의 결과를 생성하는 도구
   - `HTML 앱` — 클릭해서 바로 실행하는 인터랙티브 웹 앱 (타이머, 자리 뽑기, 게임 등)
   - `스킬 + 앱 동시에` — 같은 주제로 AI 스킬과 HTML 앱을 한 번에 생성
3. AI가 선택한 형태에 맞춰 순서대로 질문합니다.
   - 어떤 작업(또는 앱)이 필요한지
   - 어떤 정보를 입력해야 하는지 (앱은 어떤 기능·화면이 필요한지)
   - 결과물 형식·디자인은 어떻게 할지
   - 참고할 양식 파일이 있는지 (스킬·둘 다 선택 시, 건너뛰기 가능)
4. 질문이 끝나면 AI가 자동으로 만들어 줍니다.
   - AI 스킬은 위저드 화면에 초안이 열립니다. 내용을 확인하고 `저장`을 누릅니다.
   - HTML 앱은 내 스킬 목록에 바로 추가됩니다. 카드의 `열기` 버튼으로 실행하고, `수정` 버튼으로 다듬을 수 있습니다.
   - `스킬 + 앱 동시에`를 선택했다면 앱이 먼저 저장되고(이름 뒤에 "(앱)" 표시), 이어서 스킬 확인 화면이 열립니다.

### 12.3 HTML 앱 만들기

프로그래밍 지식 없이 인터랙티브 웹 앱을 만드는 방법입니다. 화면 상단의 **튜토리얼** 버튼을 누르면 앱 정보 입력·생성·미리보기·저장 방법을 단계별로 안내합니다. 팀 점수판, 모둠 편성기, 타이머, 플래시카드 등 수업에 바로 쓸 수 있는 앱을 AI가 즉시 만들어 줍니다.

1. `HTML 앱 만들기`를 누릅니다.
2. 원하는 앱을 설명하거나 아래 예시 칩 중 하나를 클릭합니다.
   - 팀별 점수판 / 랜덤 모둠 편성기 / 수업 타이머 / 어휘 플래시카드 / 칭찬 포인트 관리
3. 기능 목록에 원하는 기능을 한 줄씩 입력합니다. Enter로 줄을 추가할 수 있습니다.
   - `어휘 플래시카드` 예시를 고르면 `사과/apple`, `책/book`처럼 단어/뜻 쌍 몇 개가 미리 채워진 채 만들어져, 생성 직후 바로 카드를 넘기며 사용할 수 있습니다. 단어/뜻은 직접 추가·수정할 수 있습니다.
4. `AI로 만들기` 버튼을 누릅니다.
5. 미리보기 화면에서 앱이 작동하는지 확인합니다.
   - `코드 보기` 버튼으로 HTML 코드를 직접 수정할 수 있습니다.
   - `브라우저에서 열기` 버튼으로 전체 화면에서 사용할 수 있습니다.
6. 앱 이름과 카테고리를 입력하고 `내 스킬에 저장`을 누릅니다.
7. 내 스킬 목록에서 해당 카드의 `열기` 버튼을 누르면 브라우저에서 실행됩니다.

**앱 수정**: 내 스킬 목록에서 HTML 앱 카드의 `수정` 버튼을 누르면 앱 설명과 기능 목록을 바꾼 뒤 다시 만들 수 있습니다.

**공유**: HTML 앱도 다른 스킬과 동일하게 JSON 파일로 내보내 동료와 공유할 수 있습니다. 공유받은 앱은 전체 자료 백업에도 자동으로 포함됩니다.

### 12.4 스킬 실행

1. 내 스킬 목록에서 원하는 스킬 카드의 `실행`을 누릅니다.
2. 왼쪽에 입력 양식이 나타납니다. 항목을 채웁니다.
   - 파일 첨부가 있는 경우 파일을 올립니다. **최대 20개**까지 한 번에 올릴 수 있습니다.
3. `생성` 버튼을 누릅니다.
4. 생성 중에는 `취소` 버튼으로 중단할 수 있습니다.
5. 결과가 나오면 오른쪽 화면에서 확인하고 복사·저장합니다.

**파일 여러 개 처리**: 파일을 여러 개 올리면 한 번에 분석하여 결과를 하나의 표로 정리합니다.

**엑셀 붙여넣기**: 표로 출력된 결과는 복사 후 엑셀·구글 시트에 그대로 붙여넣기 할 수 있습니다.

**시스템 변수 자동 치환**: 스킬 프롬프트 템플릿에 아래 변수를 넣으면 설정의 값으로 자동 치환됩니다.

| 변수 | 치환되는 값 |
| --- | --- |
| `{{teacher_name}}` | 설정에서 입력한 이름 |
| `{{institution}}` | 설정에서 입력한 소속기관 |
| `{{school_level}}` | 설정에서 선택한 학교급 |

위저드로 스킬을 만들 때 이 변수들을 프롬프트에 포함하면, 매번 이름이나 소속을 따로 입력하지 않아도 됩니다.

### 12.5 스킬 공유하기

다른 선생님과 스킬을 주고받을 수 있습니다.

**내보내기 (공유하기)**
1. 내 스킬 카드의 <공유 아이콘> 버튼을 누릅니다.
2. 이름과 소속 학교를 입력합니다.
3. 선생님들께 한 마디를 입력합니다 (선택).
4. `① JSON 파일 저장하기`를 눌러 파일을 저장합니다.
5. 저장된 파일을 구글 드라이브에 올리고, 공유 링크를 복사합니다.
6. `② 공유 폼에 등록하기`를 눌러 폼을 작성합니다.

**가져오기 (파일에서)**
1. 받은 JSON 파일을 저장합니다.
2. `파일에서 가져오기` 버튼을 누릅니다.
3. 파일을 선택하면 내 스킬 목록에 추가됩니다.

**스킬마켓 탭에서 가져오기**
1. `스킬마켓` 탭을 누릅니다.
2. 동료 선생님이 등록한 스킬 목록이 나타납니다.
3. 원하는 스킬 카드의 `내 스킬에 추가`를 누릅니다.

## 13. 저장과 복사

생성 결과 화면에는 저장 버튼과 복사 버튼이 있습니다. 저장 버튼을 누르면 형식을 선택할 수 있고, 복사 버튼을 누르면 복사 형식을 선택할 수 있습니다.

**저장 형식 선택**

| 형식 | 용도 |
| --- | --- |
| PDF | 인쇄용 PDF로 저장 |
| Word | Word(HWP에서 열기 좋은 문서) 형식으로 저장 |
| HWP | HWP에서 열기 좋은 문서 형식으로 저장 |
| HWPX | 한글(HWP) 문서 파일(.hwpx)로 저장 — 제목 크기·정렬·굵은 글씨·목록·표(테두리·셀 병합 포함)가 한글 서식으로 유지됩니다 |

HWPX는 다음 기본 포맷으로 저장됩니다. 파일명에는 날짜가 붙습니다: `(YYMMDD)_제목.hwpx`

- 제목: 22pt 굵게·가운데 정렬
- 기관명(오른쪽 정렬 줄)·본문·표 안 내용: 14pt
- `1.` 수준 문단: 15pt
- `가.` 수준: 두 칸 들여쓰기, `1)` 이하 수준: 단계마다 두 칸씩 더 들여쓰기
| HTML | 웹 문서 파일로 저장 |
| MD | Markdown 형식으로 저장 |

HWPX 양식 채우기를 사용하는 경우에는 별도의 `HWPX 양식 저장` 버튼이 추가로 표시되며, 업로드한 양식의 표 구조·서식을 유지한 채 텍스트 칸만 채워 저장합니다.

**복사 형식 선택**

| 형식 | 용도 |
| --- | --- |
| HWP/웹 복사 | 결과를 복사해 HWP, Word, 웹 문서 등에 붙여넣기 |
| Excel로 복사 | 표로 출력된 결과를 엑셀·구글 시트에 그대로 붙여넣기 |
| MD로 복사 | Markdown 형식으로 복사 |

### 13.0 가정통신문·메시지 다국어 번역

가정통신문과 메세지 탭의 생성 결과 화면에는 **번역** 버튼이 있습니다. 다문화 가정 배포용 안내문을 만들 때 사용합니다.

1. 언어를 선택하고 `번역`을 누릅니다. (영어, 중국어(간체), 일본어, 베트남어, 필리핀어(타갈로그), 러시아어, 우즈베크어, 몽골어, 태국어, 캄보디아어(크메르), 인도네시아어, 네팔어, 미얀마어)
2. 번역문이 원문 아래에 함께 들어갑니다. 그대로 인쇄하거나 저장해 배포하면 됩니다.
3. 학교명·이름·날짜·연락처는 번역하지 않고 그대로 둡니다.
4. `원문만` 버튼을 누르면 번역문이 제거되고 원문만 남습니다. 다른 언어를 선택해 다시 번역하면 기존 번역문 대신 새 언어로 바뀝니다.

> 표가 들어 있는 가정통신문을 번역해도, 표가 미리보기 화면이나 저장 파일(PDF·HWPX 등) 밖으로 넘치지 않고 종이 폭 안에 들어오도록 정리됩니다. 외국어 단어가 길면 표 칸 안에서 줄바꿈됩니다.

문장 단위의 빠른 번역이 필요하면 교무행정AI의 `간단 번역` 메뉴를 사용하세요. 한국어를 외국어로, 외국어를 한국어로 양방향 번역할 수 있습니다.

### 13.1 검토 체크리스트

생성 결과 화면에는 **검토 체크리스트**가 있어 결과를 그대로 쓰기 전에 개인정보, 과장 표현, 금지 표현, 최신 지침 등을 항목별로 점검할 수 있습니다. 항목을 하나씩 확인하면서 문서를 정제하면 됩니다.

### 13.2 빠른 재작성

생성 결과 화면의 **빠른 재작성** 버튼으로 결과를 다시 다듬어 달라고 바로 요청할 수 있습니다.

- 더 짧게
- 더 공문답게
- 더 따뜻하게
- 중복 줄이기
- NEIS 다듬기

버튼을 누르면 현재 결과를 기준으로 해당 방향에 맞게 다시 작성해 줍니다.

### 13.3 개인정보 보호 모드

**개인정보 보호 모드**를 켜면 AI에게 요청을 보내기 전에 학생 이름을 임시 토큰으로 바꾸고, AI 응답을 받은 뒤 다시 원래 이름으로 복원합니다. 학생 이름이 외부 AI로 그대로 전송되는 것을 줄이고 싶을 때 사용합니다.

## 14. 전체 자료 백업과 불러오기

다른 컴퓨터에서도 EduNote 자료를 이어서 쓰려면 백업 기능을 사용합니다.

### 14.1 백업하기

1. `설정`을 엽니다.
2. `전체 자료 백업` 버튼을 누릅니다.
3. 저장할 위치를 선택합니다.
4. JSON 파일이 저장됩니다.

홈 화면의 `마지막 백업` 카드 옆에 있는 `자료 백업하기` 버튼으로도 바로 백업할 수 있습니다.

### 14.2 불러오기

1. 새 컴퓨터에서 EduNote를 실행합니다.
2. `설정`을 엽니다.
3. `백업 불러오기`를 누릅니다.
4. 이전에 저장한 JSON 파일을 선택합니다.
5. 자료가 복원되면 화면이 자동으로 새로고침되어 바로 반영됩니다. (이전 형식의 백업 파일은 새로고침 없이 앱을 다시 실행하면 반영됩니다.)

### 14.3 백업에 포함되는 것

- 기본 설정 (이름, 소속기관, 학교급 등)
- 학생 명단
- 나만의 자료실
- 학생 메모
- 내 스킬 (AI 스킬, HTML 앱, 공유받은 앱 모두 포함)
- 공문 할일 목록
- 공문 생성 히스토리, 사이드 메뉴 순서, 공문서 양식 즐겨찾기, 학생별 생성 히스토리

### 14.4 자동 정기 백업

설정 → 전체 자료 백업에서 자동 백업 주기를 선택할 수 있습니다 (매주 기본 / 매일 / 사용 안 함).

- 앱을 시작할 때 주기가 지났으면 앱 데이터 폴더의 `backups`에 백업 파일이 자동으로 만들어집니다. 저장 위치를 묻지 않습니다.
- 자동 백업 파일은 최근 10개만 보관되며, 오래된 파일은 자동으로 정리됩니다.
- 수동 백업과 마찬가지로 API 키는 포함되지 않습니다.
- 다른 컴퓨터로 옮길 때는 자동 백업 파일을 `백업 불러오기`로 선택해도 됩니다.

API 키는 보안상 백업에 포함되지 않습니다. 새 컴퓨터에서는 API 키를 다시 입력해야 합니다.

## 15. EduNote의 동작 원리 쉽게 이해하기

```text
사용자가 입력
  ↓
EduNote가 입력 내용을 정리
  ↓
Gemini API에 요청
  ↓
AI가 결과 생성
  ↓
EduNote가 결과를 문서 형태로 보여줌
  ↓
사용자가 검토 후 저장 또는 복사
```

EduNote는 사용자가 입력한 내용을 학교 업무에 맞는 형식으로 정리해 Gemini에게 보내고, 받은 결과를 문서나 수업자료 형태로 보여주는 프로그램입니다.

## 16. 인터넷 연결과 API 키가 필요한 이유

EduNote 화면과 저장 기능은 컴퓨터에서 실행되지만, AI가 글을 작성하려면 Gemini API에 접속해야 합니다.

따라서 다음 기능은 인터넷과 API 키가 필요합니다.

- 학생기록 문장 생성
- 공문서, 계획서, 보고서 생성
- 수업자료 생성
- 공문 업무추출
- 생활기록부 기재 상담

반대로 저장된 자료 보기, 자료실 확인, 메모 확인 같은 일부 기능은 이미 저장된 데이터가 있으면 로컬에서도 볼 수 있습니다.

## 17. 자주 생기는 문제와 해결 방법

### 17.1 결과가 생성되지 않을 때

확인할 것:

1. 인터넷이 연결되어 있는지 확인합니다.
2. API 키가 입력되어 있는지 확인합니다.
3. 왼쪽 아래 API 상태 문구를 확인합니다.
4. `API 일시 제한`이 보이면 잠시 기다리거나 다른 키를 사용합니다.

### 17.2 API 일시 제한이 뜰 때

가능한 원인:
- 짧은 시간에 너무 많이 요청함
- 무료 API 사용량이 잠시 제한됨
- 토큰 사용량이 많음

해결 방법:
- 잠시 기다린 뒤 다시 시도
- 입력 내용을 조금 줄여서 다시 시도
- 다른 API 키 사용
- 유료 API 키 사용 검토

> 참고: EduNote는 분당 요청 제한에 걸리면 Google이 안내한 시간만큼 자동으로 기다렸다가 다시 시도하고, 그래도 막히면 같은 API 키에서 실제 사용 가능한 다른 모델로 이어서 생성을 시도합니다. 모든 시도가 막힐 때만 위 안내가 표시되며, 하루 무료 한도를 모두 사용한 경우에는 "일일 한도 소진" 안내가 별도로 표시됩니다.

### 17.3 저장 파일을 못 찾겠을 때

1. 설정에서 저장 위치를 확인합니다.
2. 저장할 때 직접 선택한 폴더를 확인합니다.
3. Windows 다운로드 폴더나 문서 폴더도 확인합니다.

### 17.4 EduNote 실행이 막힐 때 (보안 경고)

4절 내용을 참고합니다. `추가 정보` → `실행` 순서로 진행합니다.

### 17.5 API 키 발급이 거부되고 'Google Cloud에서 만들기' 안내가 나올 때

Google AI Studio에서 `API 키 만들기`를 눌렀는데 키가 만들어지지 않고 "Google Cloud에서 만들라"는 안내가 나오는 경우가 있습니다. 아래 순서로 확인하세요.

**1) 학교/기관 계정인지 먼저 확인합니다.**

학교 Google Workspace 계정(학교 메일 주소)은 기관 관리자가 Gemini API 사용을 막아 둔 경우가 많습니다. 개인 Gmail 계정(`...@gmail.com`)으로 로그아웃 후 다시 시도해 보세요. 대부분 이 방법으로 해결됩니다.

**2) 개인 계정인데도 같은 안내가 나오면, AI Studio에서 프로젝트를 먼저 만들어 보세요. (가장 간단한 방법)**

1. [aistudio.google.com](https://aistudio.google.com)의 왼쪽 메뉴에서 `프로젝트`를 클릭합니다.
2. `새 프로젝트 만들기`를 눌러 프로젝트를 생성합니다. (이름은 자유롭게, 예: edunote)
3. 다시 왼쪽 메뉴의 `API 키` → `API 키 만들기`를 눌러 방금 만든 프로젝트를 선택하면 키가 생성됩니다.

> 이 방법으로 AI Studio 안에서 해결되는 경우가 많습니다. 안 되는 경우에만 아래 3번 방법을 시도하세요.

**3) AI Studio 방법도 안 되면, Google Cloud Console에서 직접 발급할 수 있습니다.**

1. [console.cloud.google.com](https://console.cloud.google.com)에 같은 Google 계정으로 로그인합니다.
2. 화면 상단의 프로젝트 선택을 누르고 `새 프로젝트`를 만듭니다. (이름은 자유롭게, 예: edunote)
3. 상단 검색창에 `Generative Language API`를 검색해 들어간 뒤 `사용` (영문: `Enable`) 버튼을 누릅니다.
4. 왼쪽 메뉴에서 `API 및 서비스` → `사용자 인증 정보`로 이동해 `사용자 인증 정보 만들기` → `API 키`를 누릅니다.
5. 생성된 `AIza...` 키를 복사해 EduNote 설정 화면에 붙여넣고 `테스트` 후 저장합니다.

> Cloud Console에서 발급한 키도 결제 계정을 연결하지 않은 새 프로젝트라면 무료 등급으로 동작합니다. 발급 후 5.3절의 무료/유료 등급 안내를 함께 확인하세요.

**4) 결제 정보 등록을 요구하는 경우**

먼저 다른 개인 계정으로 시도해 보세요. 그래도 같은 요구가 나오면 결제를 등록한 뒤 발급할 수 있지만, 이 경우 키가 유료 등급이 되므로 EduNote 설정에서 API 키 등급을 `유료`로 선택하고 사용량에 따라 요금이 발생할 수 있다는 점에 주의하세요.

## 18. 개인정보 사용 주의

EduNote를 사용할 때는 학생 개인정보를 조심해야 합니다.

권장 사항:
- 학생 이름은 필요한 기능에서만 사용합니다.
- 공문서나 수업자료에는 학생 명단을 자동으로 넣지 않습니다.
- 상담 내용, 민감한 가정 상황, 건강 정보는 꼭 필요한 경우가 아니면 입력하지 않습니다.
- 생성 결과는 반드시 교사가 확인하고 수정합니다.

앱의 기본 정보, 학생 명단, 학생 메모, 나만의 자료실 등은 사용자의 컴퓨터에 저장됩니다. 전체 자료 백업 파일에는 앱 자료와 설정이 포함되지만 Gemini API 키는 포함되지 않습니다. AI 기능을 사용할 때 입력한 내용은 Gemini API 요청 처리에 사용될 수 있으므로, 학생·학부모·교직원의 실명, 연락처, 주민등록번호, 건강 정보 등 민감정보는 입력하지 않는 것이 좋습니다.

## 19. 홈 화면 보는 방법

EduNote를 실행하면 처음 보이는 홈 화면 상단에 현재 앱 상태를 한눈에 확인할 수 있는 카드 4개가 1행으로 표시됩니다.

| 카드 | 표시 내용 |
| --- | --- |
| API 키 | API 키 설정 및 사용 가능 여부 |
| 사용자 정보 | 이름·소속기관 입력 여부 |
| 학생 정보 | 학생 명단 등록 여부 |
| 마지막 백업 | 가장 최근 백업을 수행한 시간 |

백업을 완료하면 마지막 백업 카드의 시간이 즉시 갱신됩니다. 아직 설정하지 않은 항목은 카드에 안내 문구가 표시되므로, 처음 사용할 때 빠짐없이 확인하기 좋습니다.

`자료 백업하기` 버튼을 누르면 현재 EduNote 자료를 바로 JSON 백업 파일로 저장할 수 있습니다.

## 20. 업데이트 알림

새 버전이 출시되면 EduNote 홈 화면에 업데이트 안내가 자동으로 표시됩니다.

안내 문구를 클릭하면 GitHub 릴리즈 페이지로 이동하여 최신 버전을 다운로드할 수 있습니다.

업데이트는 현재 파일을 삭제하고 새 파일로 교체하는 방식입니다. 설정과 자료는 별도 저장되므로 업데이트 전 백업을 권장합니다.

## 21. 처음 사용하는 분을 위한 추천 순서

1. 설정에서 API 키 입력
2. 홈 화면 둘러보기

4. 교무행정 AI에서 짧은 계획서 생성

7. 전체 자료 백업 실행

## 22. 사용 시 꼭 기억할 점

- EduNote는 문서 초안을 빠르게 만드는 도구입니다.
- 최종 책임은 사용자가 검토한 뒤 사용하는 문서에 있습니다.
- 날짜, 장소, 금액, 대상, 학생 이름은 반드시 직접 확인해야 합니다.
- 공식 문서와 생활기록부 문장은 학교 상황에 맞게 수정해야 합니다.
- API 키와 개인정보는 안전하게 관리해야 합니다.

## 23. 간단 요약

```text
1. EduNote 실행
2. 설정에서 API 키 입력
3. 왼쪽 메뉴에서 기능 선택
4. 필요한 내용 입력
5. 생성 버튼 클릭
6. 결과 확인 및 수정
7. 복사 또는 저장
8. 필요하면 전체 자료 백업
```

EduNote는 교사의 업무를 대신 끝내주는 프로그램이 아니라, 초안을 빠르게 만들고 정리 시간을 줄여 주는 업무 보조 도구입니다.
