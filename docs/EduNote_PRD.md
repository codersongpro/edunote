## 1. 앱 개요

### 1.1 기본 정보

| 항목 | 내용 |
|------|------|
| 앱 이름 | EduNote |
| 버전 | v1.14.0 |
| 플랫폼 | Windows 데스크톱 (Electron 기반) |
| 기술 스택 | Electron, React, TypeScript, Gemini API |
| 배포 형태 | 설치 불필요한 단독 실행 파일 (Portable EXE) |

### 1.2 앱 목적

EduNote는 한국 초·중·고 교사가 매일 반복해야 하는 행정 업무, 즉 학생생활기록부 작성, 공문서 처리, 수업 자료 제작에 드는 시간을 AI(인공지능)를 활용해 대폭 단축시키기 위해 만들어진 Windows 전용 데스크톱 도우미 앱입니다.

### 1.3 해결하는 문제

현장 교사들은 본연의 교육 활동 외에도 다음과 같은 행정 업무에 상당한 시간을 소비합니다.

- **학생생활기록부 작성**: 학생 1인당 행동특성 및 종합의견, 교과 세부능력 및 특기사항(세특), 창의적 체험활동 등 여러 항목을 직접 작성해야 함
- **공문서 처리**: 수시로 내려오는 공문을 읽고 업무를 추출하거나, 계획서·보고서 등 각종 문서를 작성해야 함
- **수업 자료 제작**: 수업 슬라이드, 워크시트, 퀴즈 등을 매번 직접 만들어야 함

EduNote는 이러한 반복적이고 시간 소모적인 업무를 AI가 초안을 작성해 주는 방식으로 지원하여, 교사가 학생과 직접 상호작용하는 교육 본연의 활동에 더 많은 시간을 쏟을 수 있도록 돕습니다.

### 1.3.1 v1.14.0 현행 기능 범위

v1.14.0은 HWPX 저장 품질과 실제 학교 운영 도구를 보강한 릴리즈입니다.

- HWPX 저장 시 긴 문단의 글자 겹침을 줄이기 위해 문단 길이에 맞춰 줄 배치 정보(lineseg)를 동적으로 생성합니다.
- HWPX 기본 포맷을 제목 22pt, 1. 수준 15pt, 본문·표 14pt로 맞추고, 단계별 들여쓰기를 적용합니다.
- 저장 파일명은 `(YYMMDD)_제목.hwpx` 형식을 사용하며, 본문에 없는 "생성문서" 같은 임시 제목은 넣지 않습니다.
- 양식 인쇄 도구는 별도 입력 패널 대신 A4 양식 화면을 직접 편집하고, 수정한 화면 그대로 PDF 또는 HWPX로 저장합니다.
- 문서작성기 보도자료는 제목을 별도로 입력해 생성 결과와 파일명에 반영할 수 있습니다.
- 가정통신문·메시지 결과와 간단 번역 도구에서 13개 언어 번역을 지원합니다. 러시아어와 우즈베크어를 포함합니다.
- 공문요약·업무추출 결과를 공문 할일로 저장하고, 공문 할일 화면에서 마감일·D-day·완료 여부를 관리합니다.
- 설정에서 자동 정기 백업 주기를 관리하고, 앱 시작 시 주기가 지났으면 백업을 자동 생성합니다.
- 앱 내 Demo 샘플과 사이드바 AI 스킬즈 하위메뉴를 현행 기능 기준으로 정리하고, AI 스킬즈 하위메뉴 순서도 드래그로 바꿀 수 있게 합니다.

### 1.4 앱 비전

> "모든 교사가 행정 부담 없이 교육에 집중할 수 있는 환경을 만든다."

EduNote는 복잡한 설치나 가입 절차 없이, 교사가 자신의 PC에서 바로 실행해 사용할 수 있는 실용적인 도구를 지향합니다. AI 기술을 교사의 실제 업무 흐름에 맞게 설계하여, IT에 익숙하지 않은 교사도 쉽게 활용할 수 있는 것을 목표로 합니다.

## 2. 타깃 사용자

### 2.1 주 사용자

한국 초등학교·중학교·고등학교에 재직 중인 교사

### 2.2 사용자 특성

| 특성 | 설명 |
|------|------|
| IT 친숙도 | 비전문가 수준. 스마트폰·PC 기본 사용은 가능하나 개발·기술 지식은 없음 |
| 사용 기기 | 학교 또는 개인 Windows PC |
| 업무 환경 | 학기 중 수업 준비·행정 업무가 겹쳐 매우 바쁨 |
| 주요 고충 | 반복적인 문서 작성에 드는 시간, 학교 네트워크 제한 |

### 2.3 사용 맥락

- 학기 중(3월~7월, 9월~2월) 집중적으로 사용
- 생활기록부 마감 시기(학기 말)에 사용량이 급증
- 수업 준비 시간(저녁, 주말 포함)에도 개인 PC로 사용
- 학교 방화벽·프록시 환경에서 사용하는 경우 다수

## 3. 핵심 기능 요구사항

아래 각 기능은 사용자 스토리와 수락 기준(Acceptance Criteria) 형식으로 기술합니다.

> **사용자 스토리 형식**: "나는 [역할]로서, [목표]를 위해 [기능]이 필요하다."
> **수락 기준**: 해당 기능이 제대로 동작한다고 판단하는 구체적인 조건 목록

---

### 3.1 학생기록 AI — MVP 핵심 기능

학생생활기록부의 각 항목을 AI가 초안으로 작성해 주는 기능 묶음입니다. v1.0.0의 가장 핵심 기능으로, 이 기능만으로도 교사의 업무 시간을 크게 줄일 수 있어야 합니다.

#### 3.1.1 행동특성 및 종합의견 생성

**사용자 스토리**
나는 담임교사로서, 학기말 생활기록부 마감 부담을 줄이기 위해 학생별 행동특성 및 종합의견 초안을 AI가 생성해 주는 기능이 필요하다.

**수락 기준**
- 학생 이름, 성별, 학년, 특징(교사가 메모한 내용)을 입력하면 교육부 기재요령에 맞는 분량의 문장이 생성된다.
- 생성된 결과를 화면에서 바로 수정할 수 있다.
- 결과물을 복사하거나 파일로 내보낼 수 있다.
- 학생 명단 정보는 최소한으로만 입력받으며, 로컬 기기 외부로 학생 개인정보를 전송하지 않는다.

#### 3.1.2 교과 세부능력 및 특기사항(세특) 생성

**사용자 스토리**
나는 교과 담당교사로서, 수십 명 학생 각각의 세특을 작성하는 시간을 줄이기 위해 AI가 초안을 작성해 주는 기능이 필요하다.

**수락 기준**
- 교과목, 단원명, 학생 수행 내용·특이사항을 입력하면 세특 초안이 생성된다.
- 생성 결과 수정 및 내보내기가 가능하다.

#### 3.1.3 학교스포츠클럽 특기사항 생성

**사용자 스토리**
나는 스포츠클럽 담당교사로서, 참여 학생의 특기사항 기재 시간을 단축하기 위해 AI 초안 생성 기능이 필요하다.

**수락 기준**
- 종목, 활동 내용, 학생 특성 입력 시 특기사항 초안이 생성된다.
- 결과 수정 및 복사가 가능하다.

#### 3.1.4 창의적 체험활동 특기사항 생성

**사용자 스토리**
나는 담임교사로서, 자율·동아리·봉사·진로 등 창의적 체험활동 특기사항 기재 시간을 줄이기 위해 AI 초안 생성 기능이 필요하다.

**수락 기준**
- 활동 영역(자율/동아리/봉사/진로), 활동 내용 입력 시 특기사항 초안이 생성된다.
- 결과 수정 및 내보내기가 가능하다.

---

### 3.2 설정

**사용자 스토리**
나는 교사로서, AI 기능을 사용하기 전에 내 Gemini API 키를 등록하고 기본 정보(학교급, 이름)를 입력하고 싶다.

**수락 기준**
- 설정 화면에서 Gemini API 키를 입력할 수 있다.
- API 키는 로컬 기기에 저장되며, 외부 서버로 전송되지 않는다.
- 교사 이름, 소속기관(학교명), 학년/반을 입력할 수 있다.
- 학생 명단(이름 목록)을 입력할 수 있으며, AI 생성 시 활용된다.
- 입력한 설정 값은 앱을 다시 실행해도 유지된다.

---

### 3.3 결과 출력

**사용자 스토리**
나는 교사로서, AI가 생성한 결과를 화면에서 확인하고 학교 시스템에 붙여넣거나 파일로 저장하고 싶다.

**수락 기준**
- AI 생성 결과가 화면에 표시된다.
- "복사" 버튼을 누르면 결과 텍스트가 클립보드에 복사된다.
- TXT 또는 HTML 파일로 저장할 수 있다.

---

### 3.4 앱 기반

**수락 기준**
- Windows 10, Windows 11(64비트) 환경에서 실행된다.
- 별도 설치 과정 없이 EXE 파일 실행만으로 앱이 동작한다.
- 사이드바 메뉴 구조로 각 기능 화면에 접근할 수 있다.
- 새 버전 출시 시 앱 내에서 업데이트 알림이 표시된다.

## 4. 비기능 요구사항

비기능 요구사항이란 "무엇을 하는가"가 아니라 "어떻게 동작해야 하는가"에 관한 조건입니다.

### 4.1 운영 환경

| 항목 | 요구사항 |
|------|---------|
| 지원 OS | Windows 10, Windows 11 (64비트) |
| 설치 방식 | 설치 불필요한 단독 실행 파일 (Portable EXE) |
| 최소 RAM | 4GB 이상 권장 |
| 인터넷 연결 | AI 생성 기능 사용 시 필수 |

### 4.2 보안 및 개인정보

| 항목 | 요구사항 |
|------|---------|
| API 키 저장 | 로컬 기기에 저장. 외부 서버로 전송하지 않음 |
| 학생 개인정보 | 최소 사용 원칙 적용. 필요한 정보만 입력 |
| 외부 전송 데이터 | AI 생성 요청 내용은 Google Gemini API로 전달됨. 이 외의 데이터는 외부로 전송하지 않음 |
| 로컬 저장 | 생성 결과물, 설정 데이터 등은 사용자 PC에만 저장됨 |

### 4.3 내보내기 형식

생성된 결과물은 아래 형식으로 내보낼 수 있습니다.

| 형식 | 설명 |
|------|------|
| HTML | 웹 브라우저에서 바로 열 수 있는 형식 |
| TXT | 일반 텍스트 파일 |

### 4.4 응답성 및 성능

- AI 생성 요청 후 첫 번째 응답이 30초 이내에 시작되어야 한다. (네트워크 정상 환경 기준)
- 앱 실행(로딩) 시간은 5초 이내여야 한다.

### 4.5 안정성

- 주요 기능(AI 생성, 파일 저장)에서 크래시(앱이 갑자기 꺼지는 현상) 없이 동작해야 한다.
- AI 생성 실패(네트워크 오류, API 한도 초과 등) 시 사용자에게 알기 쉬운 오류 메시지를 표시해야 한다.

## 5. 제약 사항

현재 기술적·환경적 한계로 인해 발생하는 제약 사항을 정리합니다.

### 5.1 Gemini API 의존성

- EduNote의 모든 AI 생성 기능은 Google의 Gemini API를 사용합니다.
- Google의 API 정책 변경(가격 인상, 기능 축소, 서비스 중단 등)이 발생할 경우 EduNote 기능에 영향을 받을 수 있습니다.
- 무료 등급(Free Tier)의 경우 분당 요청 수, 일일 요청 수 등의 제한이 있습니다.

### 5.2 학교 네트워크 환경

- 일부 학교에서는 방화벽이나 프록시 서버 설정으로 인해 Gemini API 연결이 차단될 수 있습니다.
- 이 경우 학교 네트워크 담당자에게 해당 도메인 허용을 요청해야 하며, EduNote 자체에서 해결할 수 없는 제약입니다.
- 개인 핫스팟(스마트폰 인터넷 공유)을 통한 우회 사용은 가능합니다.

### 5.3 Mac·Linux 미지원

- EduNote는 Windows 전용 앱입니다. Mac OS, Linux 등 다른 운영체제는 지원하지 않습니다.

| 기능 | 설명 |
|------|------|
| 상담일지 생성 | 학생 상담 후 상담일지 초안을 AI가 작성 |

| 생활기록부 기재요령 Q&A 챗봇 | 기재요령 관련 질문에 AI가 답변하는 대화형 기능 |

| 전체 자료 백업·복원 | 사용자 데이터를 파일로 내보내고 새 PC에서 복원 |

### 7.3 v2.0 — 교무행정 AI

학생기록 AI 검증 후, 교사의 또 다른 주요 업무인 학교 행정 문서 작성을 AI로 지원합니다.

| 기능 | 설명 |
|------|------|
| 학교 행정 문서 생성 | 공문서, 계획서, 보고서, 가정통신문 등 자주 쓰는 행정 문서 초안 생성 |
| 공문 업무 추출 | 수신한 공문 내용을 붙여넣으면 처리 항목과 마감일을 자동으로 추출 |
| 교무행정 챗봇 | 교무 행정 업무 중 궁금한 점을 자유롭게 질문하고 답변 |
| PDF 저장 | 생성 결과물을 A4 PDF 형식으로 저장 |
