## 1. 앱 개요

### 1.1 기본 정보

| 항목 | 내용 |
|------|------|
| 앱명 | EduNote |
| 버전 | v1.8.4 |
| 플랫폼 | Windows 데스크톱 (Electron 기반) |
| 기술 스택 | Electron, React, TypeScript, Gemini API |
| 배포 형태 | 설치 불필요한 단독 실행 파일 (Portable EXE) |

### 1.2 앱 목적

EduNote는 한국 초·중·고 교사가 매일 반복해야 하는 행정 업무, 즉 학생생활기록부 작성, 공문서 처리, 수업 자료 제작에 드는 시간을 AI(인공지능)를 활용해 대폭 단축시키기 위해 만들어진 Windows 전용 데스크톱 도우미 앱입니다.

### 1.3 해결하는 문제

현장 교사들은 본연의 교육 활동 외에도 다음과 같은 행정 업무에 상당한 시간을 소비합니다.

- **학생생활기록부 작성**: 학생 1인당 행동특성 및 종합의견, 교과 세부능력 및 특기사항(세특), 창의적 체험활동 등 여러 항목을 직접 작성해야 함
- **공문서 처리**: 수시로 내려오는 공문을 읽고 업무를 추출하거나, 계획서·보고서 등 각종 문서를 작성해야 함
- **수업 자료 제작**: 수업 슬라이드, 워크시트, 퀴즈 등을 매번 직접 만들어야 함

EduNote는 이러한 반복적이고 시간 소모적인 업무를 AI가 초안을 작성해 주는 방식으로 지원하여, 교사가 학생과 직접 상호작용하는 교육 본연의 활동에 더 많은 시간을 쏟을 수 있도록 돕습니다.

### 1.4 앱 비전

> "모든 교사가 행정 부담 없이 교육에 집중할 수 있는 환경을 만든다."

EduNote는 복잡한 설치나 가입 절차 없이, 교사가 자신의 PC에서 바로 실행해 사용할 수 있는 실용적인 도구를 지향합니다. AI 기술을 교사의 실제 업무 흐름에 맞게 설계하여, IT에 익숙하지 않은 교사도 쉽게 활용할 수 있는 것을 목표로 합니다.

## 2. 타깃 사용자

### 2.1 주 사용자

한국 초등학교·중학교·고등학교에 재직 중인 교사

### 2.2 사용자 특성

| 특성 | 설명 |
|------|------|
| IT 친숙도 | 비전문가 수준. 스마트폰·PC 기본 사용은 가능하나 개발·기술 지식은 없음 |
| 사용 기기 | 학교 또는 개인 Windows PC |
| 업무 환경 | 학기 중 수업 준비·행정 업무가 겹쳐 매우 바쁨 |
| 주요 고충 | 반복적인 문서 작성에 드는 시간, 학교 네트워크 제한 |

### 2.3 사용 맥락

- 학기 중(3월~7월, 9월~2월) 집중적으로 사용
- 생활기록부 마감 시기(학기 말)에 사용량이 급증
- 수업 준비 시간(저녁, 주말 포함)에도 개인 PC로 사용
- 학교 방화벽·프록시 환경에서 사용하는 경우 다수

## 3. 핵심 기능 요구사항

아래 각 기능은 사용자 스토리와 수락 기준(Acceptance Criteria) 형식으로 기술합니다.

> **사용자 스토리 형식**: "나는 [역할]로서, [목표]를 위해 [기능]이 필요하다."
> **수락 기준**: 해당 기능이 제대로 동작한다고 판단하는 구체적인 조건 목록

---

### 3.1 학생기록 AI

학생생활기록부의 각 항목을 AI가 초안으로 작성해 주는 기능 묶음입니다.

#### 3.1.1 행동특성 및 종합의견 생성

**사용자 스토리**
나는 담임교사로서, 학기말 생활기록부 마감 부담을 줄이기 위해 학생별 행동특성 및 종합의견 초안을 AI가 생성해 주는 기능이 필요하다.

**수락 기준**
- 학생 이름, 성별, 학년, 특징(교사가 메모한 내용)을 입력하면 교육부 기재요령에 맞는 분량의 문장이 생성된다.
- 생성된 결과를 화면에서 바로 수정할 수 있다.
- 결과물을 복사하거나 파일로 내보낼 수 있다.
- 학생 명단 정보는 최소한으로만 입력받으며, 로컬 기기 외부로 학생 개인정보를 전송하지 않는다. (AI 생성 요청 시 교사가 입력한 내용은 Gemini API로 전달되나, 불필요한 개인 식별 정보 입력을 유도하지 않는다.)

#### 3.1.2 교과 세부능력 및 특기사항(세특) 생성

**사용자 스토리**
나는 교과 담당교사로서, 수십 명 학생 각각의 세특을 작성하는 시간을 줄이기 위해 AI가 초안을 작성해 주는 기능이 필요하다.

**수락 기준**
- 교과목, 단원명, 학생 수행 내용·특이사항을 입력하면 세특 초안이 생성된다.
- 교육부 세특 기재 분량 기준(글자 수 제한)을 안내한다.
- 생성 결과 수정 및 내보내기가 가능하다.

#### 3.1.3 학교스포츠클럽 특기사항 생성

**사용자 스토리**
나는 스포츠클럽 담당교사로서, 참여 학생의 특기사항 기재 시간을 단축하기 위해 AI 초안 생성 기능이 필요하다.

**수락 기준**
- 종목, 활동 내용, 학생 특성 입력 시 특기사항 초안이 생성된다.
- 결과 수정 및 복사가 가능하다.

#### 3.1.4 창의적 체험활동 특기사항 생성

**사용자 스토리**
나는 담임교사로서, 자율·동아리·봉사·진로 등 창의적 체험활동 특기사항 기재 시간을 줄이기 위해 AI 초안 생성 기능이 필요하다.

**수락 기준**
- 활동 영역(자율/동아리/봉사/진로), 활동 내용 입력 시 특기사항 초안이 생성된다.
- 결과 수정 및 내보내기가 가능하다.

#### 3.1.5 상담일지 생성

**사용자 스토리**
나는 담임교사로서, 학생 상담 후 상담일지 작성 시간을 줄이기 위해 AI 초안 생성 기능이 필요하다.

**수락 기준**
- 상담 날짜, 학생 특성, 상담 내용 요점을 입력하면 상담일지 형식의 초안이 생성된다.
- 결과를 수정하고 문서 파일로 저장할 수 있다.

#### 3.1.6 학급경영일지 생성

**사용자 스토리**
나는 담임교사로서, 학급경영일지 작성 시간을 줄이기 위해 AI 초안 생성 기능이 필요하다.

**수락 기준**
- 날짜, 주요 학급 활동, 특이사항 입력 시 학급경영일지 초안이 생성된다.
- 결과 수정 및 저장이 가능하다.

#### 3.1.7 생활기록부 기재요령 챗봇 Q&A

**사용자 스토리**
나는 교사로서, 생활기록부 작성 중 모르는 기재요령을 즉시 검색·질문하여 답변을 받고 싶다.

**수락 기준**
- 텍스트로 질문을 입력하면 AI가 생활기록부 기재요령 관련 답변을 제공한다.
- 대화 형식으로 추가 질문을 이어갈 수 있다.
- 답변 내용에 출처나 참고 기준을 함께 제시한다.

### 3.2 교무행정 AI

학교 행정 문서 작성 및 업무 관리를 AI가 지원하는 기능 묶음입니다.

#### 3.2.1 9종 학교 문서 생성

지원 문서 종류: 공문서, 계획서, 보고서, 품의서(결재 요청 문서), 회의록, 홍보자료, 가정통신문, 문자·소통메시지, 공고문

**사용자 스토리**
나는 업무 담당교사로서, 각종 학교 행정 문서를 처음부터 작성하는 시간을 줄이기 위해 AI가 형식에 맞는 초안을 작성해 주는 기능이 필요하다.

**수락 기준**
- 문서 종류 선택 후 제목, 목적, 주요 내용을 입력하면 해당 양식에 맞는 초안이 생성된다.
- 공문서·품의서 등은 학교 공문 형식(두문, 본문, 결문 구조)을 따른다.
- 생성된 문서를 화면에서 수정하고, 지정 형식으로 내보낼 수 있다.
- 9종 문서 각각에 대해 입력 화면과 생성 결과가 구분되어 표시된다.

#### 3.2.2 공문 업무추출 및 Google Calendar 연동

**사용자 스토리**
나는 업무 담당교사로서, 수신된 공문 내용을 붙여넣으면 처리해야 할 업무와 마감일을 자동으로 추출하고, 이를 내 Google Calendar에 등록하고 싶다.

**수락 기준**
- 공문 텍스트를 입력하면 AI가 처리 항목, 담당자, 마감일을 추출하여 목록으로 표시한다.
- 추출된 업무를 Google Calendar에 일정으로 등록하는 기능이 제공된다.
- Google 계정 연동(OAuth 인증) 후 캘린더 등록이 가능하다.
- 연동 실패 시 사용자에게 오류 메시지가 표시된다.

#### 3.2.3 교무행정 챗봇

**사용자 스토리**
나는 교사로서, 교무 행정 업무 중 궁금한 점을 자유롭게 질문하고 답변을 받고 싶다.

**수락 기준**
- 텍스트 질문 입력 시 AI가 교무 행정 관련 답변을 제공한다.
- 이전 대화 맥락을 유지하여 연속 질문이 가능하다.

### 3.3 수업 AI

수업 준비와 자료 제작을 AI가 지원하는 기능 묶음입니다.

#### 3.3.1 수업 슬라이드 생성

**사용자 스토리**
나는 교사로서, 수업 주제를 입력하면 AI가 슬라이드 형태의 수업 자료 초안을 생성해 주는 기능이 필요하다.

**수락 기준**
- 교과목, 학년, 단원명, 학습 목표를 입력하면 슬라이드 구성(제목, 내용, 이미지 자리 등)이 포함된 초안이 생성된다.
- 생성된 슬라이드를 HTML 또는 PDF 형식으로 내보낼 수 있다.
- 슬라이드 항목별 내용을 수정할 수 있다.

#### 3.3.2 워크시트·평가지 생성

**사용자 스토리**
나는 교사로서, 단원별 학습 확인을 위한 워크시트와 평가지를 AI가 초안으로 만들어 주는 기능이 필요하다.

**수락 기준**
- 교과목, 단원, 난이도, 문항 수를 입력하면 워크시트 또는 평가지 초안이 생성된다.
- 문항 유형(단답형, 서술형, 빈칸 채우기 등)을 선택할 수 있다.
- 생성 결과를 PDF 또는 문서 파일로 내보낼 수 있다.

#### 3.3.3 퀴즈 앱 생성

**사용자 스토리**
나는 교사로서, 수업 중 학생들과 함께 할 수 있는 인터랙티브 퀴즈를 손쉽게 만들고 싶다.

**수락 기준**
- 객관식, 주관식, OX 퀴즈 유형을 지원한다.
- AI가 주제를 바탕으로 퀴즈 문항을 생성하거나, 교사가 직접 문항을 입력할 수 있다.
- 퀴즈 데이터는 JSON 형식으로 저장되며, 고정된 HTML 템플릿에 적용되어 퀴즈 앱이 생성된다.
- 생성된 퀴즈 앱은 브라우저에서 바로 실행 가능한 HTML 파일로 내보낼 수 있다.
- 학생이 퀴즈를 풀고 결과(정답 여부, 점수)를 즉시 확인할 수 있다.

#### 3.3.4 수업 계획서 생성

**사용자 스토리**
나는 교사로서, 수업 지도안(계획서) 작성 시간을 줄이기 위해 AI가 초안을 만들어 주는 기능이 필요하다.

**수락 기준**
- 교과목, 학년, 단원, 학습 목표, 수업 시간, 수업 방법을 입력하면 지도안 형식의 초안이 생성된다.
- 도입-전개-정리 구조를 포함한 단계별 수업 흐름이 제시된다.
- 결과를 문서 파일로 내보낼 수 있다.

#### 3.3.5 수업관찰기록 생성

**사용자 스토리**
나는 교사로서, 수업 후 수업관찰기록 작성 시간을 줄이기 위해 AI 초안 생성 기능이 필요하다.

**수락 기준**
- 수업 날짜, 교과, 단원, 관찰 내용 요점을 입력하면 수업관찰기록 초안이 생성된다.
- 결과 수정 및 저장이 가능하다.

### 3.4 수업 운영 도구

수업 중 또는 학급 운영에 바로 활용할 수 있는 보조 도구 묶음입니다.

#### 3.4.1 QR 메이커

**사용자 스토리**
나는 교사로서, URL이나 텍스트를 QR 코드로 빠르게 만들어 수업 자료나 안내문에 삽입하고 싶다.

**수락 기준**
- URL 또는 텍스트 입력 시 QR 코드 이미지가 즉시 생성된다.
- 생성된 QR 코드를 이미지 파일(PNG 등)로 저장할 수 있다.
- QR 코드 크기 또는 색상 조정 옵션을 제공한다.

#### 3.4.2 나만의 자료실

**사용자 스토리**
나는 교사로서, 수업에 참고할 YouTube 영상이나 웹페이지를 저장·분류하여 필요할 때 빠르게 찾고 싶다.

**수락 기준**
- YouTube URL 또는 웹페이지 URL을 입력하면 썸네일 이미지와 제목이 자동으로 가져와진다.
- 저장된 자료에 태그 또는 카테고리를 붙여 분류할 수 있다.
- 제목, 태그, 메모로 자료를 검색할 수 있다.
- 저장 자료는 로컬 기기에 저장된다.

#### 3.4.3 오늘의 주인공 추첨

**사용자 스토리**
나는 담임교사로서, 수업 중 무작위로 학생을 공정하게 선정하고 싶다.

**수락 기준**
- 학생 이름 목록을 입력하면 무작위로 1명 이상을 선정하는 추첨이 가능하다.
- 추첨 결과가 화면에 명확하게 표시된다.
- 동일 학생이 중복 추첨되지 않도록 이미 선정된 학생을 제외하는 옵션을 제공한다.

#### 3.4.4 학생 메모 보드

**사용자 스토리**
나는 담임교사로서, 학생별 간단한 메모(특이사항, 상담 내용 등)를 앱 안에서 관리하고 싶다.

**수락 기준**
- 학생 이름별로 메모를 작성·수정·삭제할 수 있다.
- 메모는 로컬 기기에 저장되며, 앱 재시작 후에도 유지된다.
- 학생 이름 또는 메모 내용으로 검색이 가능하다.

### 3.5 시스템 기능

앱 전반의 편의성과 안정성을 위한 기능 묶음입니다.

#### 3.5.1 Gemini API 등급 선택

**사용자 스토리**
나는 교사로서, 내 Gemini API 키(무료 또는 유료)를 앱에 등록하고 사용 등급에 맞게 기능을 이용하고 싶다.

**수락 기준**
- 설정 화면에서 Gemini API 키를 입력할 수 있다.
- 무료(Free Tier)와 유료(Paid Tier) 등급을 선택할 수 있으며, 등급에 따라 사용 가능한 모델이 달라진다.
- API 키는 로컬 기기에 암호화하여 저장된다. (외부 서버로 API 키가 전송되지 않는다.)
- API 키 유효성 검증 기능을 제공한다.

#### 3.5.2 업데이트 알림 (GitHub Releases 기반)

**사용자 스토리**
나는 교사로서, 새 버전이 출시되면 앱에서 알림을 받고 최신 버전을 쉽게 내려받고 싶다.

**수락 기준**
- 앱 실행 시 GitHub Releases에서 최신 버전 정보를 확인한다.
- 현재 버전보다 높은 버전이 있으면 업데이트 알림 배너 또는 팝업이 표시된다.
- 알림에서 직접 다운로드 페이지로 이동할 수 있다.
- 네트워크 미연결 상태에서는 알림 없이 정상 실행된다.

#### 3.5.3 전체 자료 백업·복원

**사용자 스토리**
나는 교사로서, PC 교체나 초기화에 대비해 내 자료(생성 결과물, 저장 메모, 자료실 등)를 백업하고 새 PC에서 복원하고 싶다.

**수락 기준**
- 백업 버튼 클릭 시 모든 로컬 저장 데이터를 하나의 파일로 내보낼 수 있다.
- 복원 버튼 클릭 시 백업 파일을 불러와 데이터를 복구할 수 있다.
- 복원 전 기존 데이터 덮어쓰기 여부를 사용자에게 확인한다.

#### 3.5.4 다크모드

**사용자 스토리**
나는 교사로서, 야간 작업 시 눈의 피로를 줄이기 위해 화면을 어둡게 전환하고 싶다.

**수락 기준**
- 설정 또는 상단 버튼으로 다크모드와 라이트모드 간 전환이 가능하다.
- 선택한 모드는 앱 재시작 후에도 유지된다.
- 모든 화면(메뉴, 입력 폼, 결과 화면)에 다크모드가 일관되게 적용된다.

#### 3.5.5 메뉴 드래그 재정렬

**사용자 스토리**
나는 교사로서, 자주 쓰는 기능을 사이드바 메뉴에서 상단으로 옮겨 빠르게 접근하고 싶다.

**수락 기준**
- 사이드바 메뉴 항목을 드래그 앤 드롭으로 순서를 바꿀 수 있다.
- 변경된 순서는 앱 재시작 후에도 유지된다.

#### 3.5.6 생성 중단 기능

**사용자 스토리**
나는 교사로서, AI 생성 중에 원하지 않는 방향으로 진행될 경우 즉시 중단하고 싶다.

**수락 기준**
- AI 생성이 진행되는 동안 "중단" 버튼이 화면에 표시된다.
- 중단 버튼 클릭 시 생성이 즉시 멈추고, 현재까지 생성된 내용이 화면에 남는다.
- 중단 후 다시 생성을 요청할 수 있다.

## 4. 비기능 요구사항

비기능 요구사항이란 "무엇을 하는가"가 아니라 "어떻게 동작해야 하는가"에 관한 조건입니다.

### 4.1 운영 환경

| 항목 | 요구사항 |
|------|---------|
| 지원 OS | Windows 10, Windows 11 (64비트) |
| 설치 방식 | 설치 불필요한 단독 실행 파일 (Portable EXE) |
| 최소 RAM | 4GB 이상 권장 |
| 인터넷 연결 | AI 생성 기능 사용 시 필수. 자료실·메모·추첨 등 로컬 기능은 오프라인에서도 동작 |

### 4.2 보안 및 개인정보

| 항목 | 요구사항 |
|------|---------|
| API 키 저장 | 로컬 기기에 암호화(Encryption)하여 저장. 외부 서버로 전송하지 않음 |
| 학생 개인정보 | 최소 사용 원칙 적용. 학생 명단 전체를 입력받는 구조를 지양하고, 필요한 정보만 입력 |
| 외부 전송 데이터 | AI 생성 요청 내용은 Google Gemini API로 전달됨. 이 외의 데이터는 외부로 전송하지 않음 |
| 로컬 저장 | 생성 결과물, 메모, 자료실 데이터 등은 사용자 PC에만 저장됨 |

### 4.3 내보내기 형식

생성된 결과물은 아래 형식으로 내보낼 수 있습니다.

| 형식 | 설명 |
|------|------|
| HTML | 웹 브라우저에서 바로 열 수 있는 형식 |
| PDF | 인쇄 및 공유에 적합한 문서 형식 |
| TXT | 일반 텍스트 파일 |
| Markdown | 마크다운 형식 텍스트 파일 |
| Doc (DOCX) | Microsoft Word 호환 문서 형식 |

### 4.4 응답성 및 성능

- AI 생성 요청 후 첫 번째 응답(텍스트)이 30초 이내에 시작되어야 한다. (네트워크 정상 환경 기준)
- 앱 실행(로딩) 시간은 5초 이내여야 한다.
- 로컬 기능(자료실 검색, 메모 조회 등)은 1초 이내에 결과가 표시되어야 한다.

### 4.5 안정성

- 주요 기능(AI 생성, 파일 내보내기, 데이터 저장)에서 크래시(앱이 갑자기 꺼지는 현상) 없이 동작해야 한다.
- AI 생성 실패(네트워크 오류, API 한도 초과 등) 시 사용자에게 알기 쉬운 오류 메시지를 표시해야 한다.

## 5. 제약 사항

현재 기술적·환경적 한계로 인해 발생하는 제약 사항을 정리합니다.

### 5.1 Gemini API 의존성

- EduNote의 모든 AI 생성 기능은 Google의 Gemini API를 사용합니다.
- Google의 API 정책 변경(가격 인상, 기능 축소, 서비스 중단 등)이 발생할 경우 EduNote 기능에 영향을 받을 수 있습니다.
- 무료 등급(Free Tier)의 경우 분당 요청 수, 일일 요청 수 등의 제한이 있습니다.

### 5.2 HWPX 저장 (한글 파일 형식)

- 한국 공공기관에서 널리 사용하는 HWP/HWPX 형식 저장은 현재 실험적(Experimental) 기능으로 제공됩니다.
- 모든 서식과 내용이 완벽하게 변환되지 않을 수 있으며, 정식 기능으로 전환 전까지 안정성이 보장되지 않습니다.

### 5.3 학교 네트워크 환경

- 일부 학교에서는 방화벽(외부 인터넷 차단 장치)이나 프록시 서버(인터넷 중간 중계 서버) 설정으로 인해 Gemini API 연결이 차단될 수 있습니다.
- 이 경우 학교 네트워크 담당자에게 해당 도메인 허용을 요청해야 하며, EduNote 자체에서 해결할 수 없는 제약입니다.
- 개인 핫스팟(스마트폰 인터넷 공유)을 통한 우회 사용은 가능합니다.

### 5.4 Mac·Linux 미지원

- EduNote는 Windows 전용 앱입니다. Mac OS, Linux 등 다른 운영체제는 지원하지 않습니다.
